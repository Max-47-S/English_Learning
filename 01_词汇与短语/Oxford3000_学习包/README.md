## 音频怎么用

完整 MP3 时长 **2 小时 3 分 47 秒**，约 **59.4 MB**。3,306 个条目全部使用真人录音，**AI 配音为 0**。没有找到可核实与该 PDF 完全同序的现成连续音频，因此使用开放许可的真人单词录音，重新按 PDF 顺序拼接。不同说话人的音色、音量和口音会有差别，已统一采样率并调整音量。

| 级别 | 完整 MP3 中的起点 |

| B1 | 01:04:46 |

音频只朗读英文词头，不朗读中文、搭配或例句。PDF 同一行若有不同常见读音，会尽量读出对应词性的读音；这不是逐词列举全部英美发音变体的发音词典。`a, an` 一条读两个冠词；CD、DVD、IT 由真人字母录音拼接；`ought to` 由真人单词录音拼接。`used¹` 为体现“习惯于”的读音读作 `used to`，与“二手的” `used²` 区分，并在对应条目中注明。

直接听：把 MP3 与同名 LRC 放在一起，使用支持歌词的播放器打开 MP3。即使没有 LRC，也可以正常连续播放。

按词跳转：保留 `连续听读.html` 与 `audio/` 文件夹的相对位置，在浏览器中打开 HTML。无需安装 Python 或其他依赖。点击某个词后，将从该词继续播放完整词序；搜索和级别筛选只改变列表。进度保存在当前浏览器本机；浏览器清理数据或更换设备后不会自动同步。

单条复习：无论正在播放还是暂停，点击“上一词”“下一词”或“重听本词”后，都只播放目标词条并在读完后暂停。点击音频栏的播放按钮或拖动进度条，恢复连续播放。

手机使用：把学习包复制到手机，先解压，再用浏览器打开 HTML；部分手机文件预览器不允许 HTML 读取同目录媒体，此时直接用音乐播放器打开 MP3 即可。GitHub 普通文件预览不会运行本地 HTML 播放器，需要下载文件后打开。Markdown 中的音频时间链接是否直接跳转，取决于阅读器；HTML 播放器支持按词定位。

## 学习材料的范围

3,306 是 PDF 的**学习条目数**，包含不同词性、义项、级别的重复；不是 3,306 个互不重复的单词。当前任务覆盖完整 PDF，因此也包含 apple 等具体名词。

中文释义优先呈现常用含义，结合词性、PDF 的限定词和例句理解。搭配一栏包含常用结构及从例句提取的语境用法，后者不一定是固定短语。词形来自词典资料并对部分同形异义词作了修正；并非每种词形都适用于该词的所有义项。

例句包含 617 条原创学习例句和 2,689 条带署名的 Tatoeba/ManyThings 语料例句。中文已转为简体；部分英语词语或拼写按 PDF 调整，并保留原作者署名。整理版主要用于记忆和跟读，词条没有完整列出所有义项、语法限制或发音变体；不是牛津官方配套释义或官方有声书。

建议每次学习 30–50 个条目：先听词头，遮住中文回忆，再用搭配和例句复述；第二遍只复习未能立即回忆的词。
