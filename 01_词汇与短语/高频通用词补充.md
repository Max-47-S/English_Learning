# 高频通用词补充

> 本表收录 **180 个单词词头**：80 个通用动词、50 个副词、30 个形容词或限定用词、20 个通用或抽象名词。词头不重复，也不与《英语封闭词类总览》表格中的 237 个单列拼写项重复；原文正文或短语中出现过的词，仍可能在这里首次单独列为学习词条。

本表优先选择跨话题常用、能参与许多句型和搭配的词，如 `become`、`get`、`make`、`seem`、`mean`。不收录以具体物品名称为主的词。许多入选词仍是实义词，筛选依据是通用性和表达覆盖面。

180 个词头均已逐一与 [Oxford 3000 官方英式词表](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000.pdf) 核对。Oxford 3000 根据频率和学习相关性选词，覆盖 A1–B2；本表的分组和学习顺序是教学整理，不是官方词频排名。词头入选也不表示其所有义项、短语和句式处在同一等级。参见 [Oxford 词表说明](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000)。

`become` 是实义动词，在 `become better` 中作系动词，不属于 `be` 的变形。这里把它与其他通用词单列，便于在封闭词类之外继续学习。参见 [Cambridge：动词类型与系动词](https://dictionary.cambridge.org/us/grammar/british-grammar/verbs-types?q=linking+verbs)。

配套文件：[原封闭词类总览](../02_语法笔记/英语封闭词类总览.md) · [词汇数量统计与计数口径](词汇数量统计.md)

## 怎么看这份词表

- 每行第一列是正式收录的词头；中文义项、搭配示例里的其他词不另计数。
- `do` 表示动词原形位置，`doing` 表示相应的 -ing 形式，`someone`、`something` 表示可替换的人或事物。
- 先学“中文核心义 + 一两个句式”，再逐步扩展其他义项。表内只展示部分常见用法。
- 原表已有的 `be`、`have`、`do`、`need`、`like` 也很重要，本表不另占一个新词名额；其中 `like` 作动词时表示“喜欢”。

建议先掌握这 20 个词及其表内搭配：

`become`, `get`, `make`, `take`, `give`, `put`, `go`, `come`, `keep`, `seem`, `know`, `think`, `mean`, `find`, `want`, `use`, `work`, `help`, `try`, `allow`。

## 容易混淆的句式

| 句式 | 区别 |
| --- | --- |
| `remember to do` / `remember doing` | 前者是记得去做，后者是记得做过。 |
| `forget to do` / `forget doing` | 前者是忘记去做，后者是忘记做过。 |
| `try to do` / `try doing` | 前者强调努力完成，后者强调试一种方法。 |
| `stop doing` / `stop to do` | 前者是停止当前动作，后者是停下来去做另一件事。 |
| `used to do` / `be used to doing` / `be used for doing` | 分别表示过去常常做、习惯于做、被用于做。 |
| `suggest doing` | 表示建议做某事，避免误用成 `suggest someone to do`。 |
| `explain something to someone` | 表示向某人解释某事，避免误用成 `explain someone something`。 |

本表是第一批学习清单，不是高频通用词的穷尽集合。熟悉这些词后，应优先积累它们在阅读材料中的新搭配。
