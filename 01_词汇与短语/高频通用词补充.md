# 高频通用词补充

> 本表收录 **180 个单词词头**：80 个通用动词、50 个副词、30 个形容词或限定用词、20 个通用或抽象名词。词头不重复，也不与《英语封闭词类总览》表格中的 237 个单列拼写项重复；原文正文或短语中出现过的词，仍可能在这里首次单独列为学习词条。

本表优先选择跨话题常用、能参与许多句型和搭配的词，如 `become`、`get`、`make`、`seem`、`mean`。不收录以具体物品名称为主的词。许多入选词仍是实义词，筛选依据是通用性和表达覆盖面。

180 个词头均已逐一与 [Oxford 3000 官方英式词表](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000.pdf) 核对。Oxford 3000 根据频率和学习相关性选词，覆盖 A1–B2；本表的分组和学习顺序是教学整理，不是官方词频排名。词头入选也不表示其所有义项、短语和句式处在同一等级。参见 [Oxford 词表说明](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000)。

`become` 是实义动词，在 `become better` 中作系动词，不属于 `be` 的变形。这里把它与其他通用词单列，便于在封闭词类之外继续学习。参见 [Cambridge：动词类型与系动词](https://dictionary.cambridge.org/us/grammar/british-grammar/verbs-types?q=linking+verbs)。

## 怎么看这份词表

- 每行第一列是正式收录的词头；中文义项、搭配示例里的其他词不另计数。
- `do` 表示动词原形位置，`doing` 表示相应的 -ing 形式，`someone`、`something` 表示可替换的人或事物。
- 先学“中文核心义 + 一两个句式”，再逐步扩展其他义项。表内只展示部分常见用法。
- 每个分类表格下有对应的**原创双语语境例句**；粗体标出目标词或它在句子中的实际形式（如 `sound → sounds`、`manage → managed`）。先读完整句子或两句组成的上下文，再判断本句中的意思。
- 同一词有多种常用含义时，分开给句子；例句中的其他词不另计为本表词头。
- 原表已有的 `be`、`have`、`do`、`need`、`like` 也很重要，本表不另占一个新词名额；其中 `like` 作动词时表示“喜欢”。

## 1. 通用动词（80 词）

### 1.1 状态、变化与呈现（12 词）

| 单词 | 核心义 | 常见搭配或句式 |
| --- | --- | --- |
| `become` | 变成；成为 | `become better`；`become a habit` |
| `get` | 得到；变得；使某人做 | `get better`；`get something`；`get someone to do` |
| `seem` | 似乎；看来 | `seem useful`；`seem to do` |
| `appear` | 出现；显得；似乎 | `appear different`；`appear to do` |
| `remain` | 保持；仍然是；留下 | `remain calm`；`remain a problem` |
| `stay` | 保持；停留 | `stay calm`；`stay in a place` |
| `keep` | 保持；继续；保留 | `keep quiet`；`keep doing`；`keep something safe` |
| `turn` | 转变；转动 | `turn red`；`turn into something` |
| `grow` | 增长；逐渐变得 | `grow stronger`；`grow into something` |
| `feel` | 感觉；感到 | `feel better`；`feel that ...` |
| `look` | 看；看起来 | `look useful`；`look at something` |
| `sound` | 听起来 | `sound good`；`sound like something` |


**语境例句**

- **become｜变成；成为**：After a month of daily practice, I have **become** more confident. → 每天练习一个月后，我变得更有信心了。

- **get｜得到；变得；使某人做**：

  - Can you **get** some information about the course? → 你能弄到一些有关这门课程的信息吗？
  - It may **get** cold tonight, so take a coat. → 今晚可能会变冷，所以带件外套。
  - I can't **get** the printer to work. → 我没法让打印机正常工作。

- **seem｜似乎；看来**：You **seem** tired. Did you sleep well? → 你看起来很累，昨晚睡得好吗？

- **appear｜出现；显得；似乎**：

  - Two names **appear** on the list, but I expected three. → 名单上出现了两个名字，但我原以为有三个。
  - They **appear** to know each other already. → 他们似乎已经认识了。

- **remain｜保持；仍然是；留下**：Please **remain** calm while we check the problem. → 我们检查问题时，请保持冷静。

- **stay｜保持；停留**：

  - You can **stay** here until the rain stops. → 你可以留在这里，等雨停了再走。
  - Try to **stay** focused during the final ten minutes. → 最后十分钟尽量保持专注。

- **keep｜保持；继续；保留**：

  - Please **keep** the receipt in case you need to return it. → 请保留收据，以防需要退货。
  - I **keep** forgetting her name, although we've met twice. → 虽然见过两次，我还是总忘记她的名字。

- **turn｜转变；转动**：The leaves **turn** yellow in autumn. → 树叶在秋天变黄。

- **grow｜增长；逐渐变得**：

  - Your confidence will **grow** as you practise. → 随着练习，你的信心会增强。
  - The room began to **grow** quiet as the speaker stood up. → 演讲者站起来时，房间里渐渐安静下来。

- **feel｜感觉；感到**：

  - I **feel** better after a short walk. → 散步一小会儿后，我感觉好多了。
  - I **feel** that we need more time to discuss this. → 我觉得我们需要更多时间讨论这件事。

- **look｜看；看起来**：

  - These instructions **look** simple, but the task is quite difficult. → 这些说明看起来简单，但任务相当难。
  - Please **look** at the final paragraph before you reply. → 回复前，请看一下最后一段。

- **sound｜听起来**：Your plan **sounds** useful. Let's try it tomorrow. → 你的计划听起来很有用，我们明天试试吧。

### 1.2 通用动作、结果与传递（14 词）

| 单词 | 核心义 | 常见搭配或句式 |
| --- | --- | --- |
| `make` | 做出；使得 | `make progress`；`make it clear`；`make someone do` |
| `take` | 拿；花费；采取 | `take time`；`take action` |
| `give` | 给；提供 | `give someone something`；`give something to someone` |
| `put` | 放置；使处于某状态 | `put something here`；`put something into practice` |
| `bring` | 带来；促成 | `bring something to someone`；`bring about a change` |
| `leave` | 离开；留下；使保持某状态 | `leave a place`；`leave it open` |
| `set` | 设定；设置 | `set a goal`；`set something up` |
| `hold` | 持有；容纳；举行 | `hold a view`；`hold a meeting` |
| `let` | 让；允许 | `let someone do`；`let go of something` |
| `go` | 去；进行；变得 | `go home`；`go well`；`go wrong` |
| `come` | 来；达到；逐渐开始 | `come here`；`come to understand`；`come up with an idea` |
| `move` | 移动；推动进展 | `move forward`；`move from one stage to another` |
| `change` | 改变；变化 | `change something`；`change into something` |
| `happen` | 发生；碰巧 | `happen to someone`；`happen to do` |


**语境例句**

- **make｜做出；使得**：

  - Small changes can **make** a big difference. → 小小的改变也能产生很大的影响。
  - Please **make** it clear that everyone is welcome. → 请说清楚，每个人都可以参加。
  - Don't **make** her wait outside in the rain. → 别让她在外面淋着雨等。

- **take｜拿；花费；采取**：

  - Please **take** this note to the office. → 请把这张便条带到办公室。
  - It will **take** two hours to check all the files. → 检查完所有文件需要两个小时。
  - We need to **take** action before the problem gets worse. → 我们需要在问题恶化前采取行动。

- **give｜给；提供**：Could you **give** me a little more time to decide? → 你能再给我一点时间作决定吗？

- **put｜放置；使处于某状态**：

  - Please **put** the keys beside the door so I can find them. → 请把钥匙放在门旁边，好让我能找到。
  - We need to **put** this idea into practice. → 我们需要把这个想法付诸实践。

- **bring｜带来；促成**：

  - Please **bring** your notes to the next meeting. → 下次开会请带上你的笔记。
  - A clearer explanation could **bring** about a useful change. → 更清楚的解释可能促成有益的改变。

- **leave｜离开；留下；使保持某状态**：

  - What time do you **leave** home for work? → 你几点离开家去上班？
  - Please **leave** the window open; it's hot in here. → 请让窗户开着，这里很热。

- **set｜设定；设置**：Let's **set** a realistic goal for this week. → 我们给这周定一个切实可行的目标吧。

- **hold｜持有；容纳；举行**：

  - We will **hold** a short meeting after lunch. → 午饭后我们会开一个简短的会议。
  - I **hold** a different view, but I understand your reasons. → 我的看法不同，但我理解你的理由。

- **let｜让；允许**：

  - **Let** me finish this sentence before you ask your question. → 让我先把这句话说完，你再提问。
  - You can **let** go of the handle now; the door will stay open. → 你现在可以松开把手了，门会保持开着。

- **go｜去；进行；变得**：

  - I usually **go** home at six. → 我通常六点回家。
  - I hope the meeting will **go** well. → 我希望会议能顺利进行。
  - Something may **go** wrong, so save a copy first. → 可能会出问题，所以先保存一份副本。

- **come｜来；达到；逐渐开始**：

  - Can you **come** here for a moment? → 你能过来一下吗？
  - With practice, you will **come** to understand the difference. → 经过练习，你会逐渐理解其中的区别。

- **move｜移动；推动进展**：

  - Could you **move** your chair a little closer? → 你能把椅子移近一点吗？
  - We've agreed on the goal; now we can **move** forward. → 目标已经商定了，现在我们可以继续推进。

- **change｜改变；变化**：We need to **change** the date because several people are away. → 我们需要改一下日期，因为有几个人不在。

- **happen｜发生；碰巧**：

  - Mistakes can **happen** when you're tired. → 累的时候可能会出错。
  - If you **happen** to see Mia, ask her to call me. → 如果你碰巧见到米娅，请让她给我打电话。

### 1.3 思考、感知与判断（12 词）

| 单词 | 核心义 | 常见搭配或句式 |
| --- | --- | --- |
| `know` | 知道；了解 | `know about something`；`know that ...` |
| `think` | 想；认为 | `think about something`；`think that ...` |
| `believe` | 相信；认为 | `believe that ...`；`believe in someone` |
| `understand` | 理解；明白 | `understand something`；`understand why ...` |
| `mean` | 意味着；打算 | `mean doing`；`mean to do` |
| `find` | 发现；觉得 | `find it useful`；`find that ...` |
| `see` | 看见；明白；看待 | `see why ...`；`see something as ...` |
| `hear` | 听见；听说 | `hear about something`；`hear that ...` |
| `remember` | 记得；记住 | `remember to do`；`remember doing` |
| `forget` | 忘记 | `forget to do`；`forget doing` |
| `consider` | 考虑；认为 | `consider doing`；`consider it useful` |
| `suppose` | 认为；假设；应当 | `suppose that ...`；`be supposed to do` |


**语境例句**

- **know｜知道；了解**：Do you **know** why the meeting was cancelled? → 你知道会议为什么取消了吗？

- **think｜想；认为**：

  - I **think** this version is easier to read. → 我认为这个版本更容易读懂。
  - Give me a day to **think** about your suggestion. → 给我一天时间考虑你的建议。

- **believe｜相信；认为**：

  - I **believe** that he gave us the correct address. → 我相信他给我们的地址是对的。
  - I **believe** in you, even if this task feels difficult. → 即使这项任务让你觉得困难，我也相信你的能力。

- **understand｜理解；明白**：I **understand** the words, but I don't **understand** why she said them. → 这些词我认识，但我不明白她为什么这样说。

- **mean｜意味着；打算**：

  - Finishing tonight will **mean** working late. → 今晚完成就意味着要工作到很晚。
  - I didn't **mean** to interrupt you; I thought you had finished. → 我不是有意打断你，我以为你已经说完了。

- **find｜发现；觉得**：

  - I **find** this example useful because it gives a clear context. → 我觉得这个例子很有用，因为它提供了明确的语境。
  - I often **find** useful phrases in everyday emails. → 我经常在日常邮件中发现有用的表达。

- **see｜看见；明白；看待**：

  - I can **see** your screen, but the text is too small to read. → 我能看见你的屏幕，但文字太小，读不清。
  - Now I **see** why you wanted to check it again. → 现在我明白你为什么想再检查一遍了。

- **hear｜听见；听说**：

  - Did you **hear** the noise outside? → 你听见外面的响声了吗？
  - I was sorry to **hear** that your trip had been cancelled. → 听说你的旅行取消了，我感到很遗憾。

- **remember｜记得；记住**：

  - Please **remember** to save the file before you close it. → 关闭文件前，请记得保存。
  - I **remember** saving it, but I can't find it now. → 我记得保存过它，但现在找不到了。

- **forget｜忘记**：

  - Don't **forget** to send me the address. → 别忘了把地址发给我。
  - I'll never **forget** seeing the sea for the first time. → 我永远不会忘记第一次看到大海的情景。

- **consider｜考虑；认为**：

  - We're **considering** moving closer to work. → 我们正在考虑搬到离上班地点更近的地方。
  - I **consider** this a useful starting point. → 我认为这是一个有用的起点。

- **suppose｜认为；假设；应当**：

  - I **suppose** you're right, although I'm still not completely sure. → 我想你是对的，虽然我还不是完全确定。
  - We're **supposed** to arrive before nine. → 按约定，我们应在九点前到达。

### 1.4 意愿、选择与尝试（10 词）

| 单词 | 核心义 | 常见搭配或句式 |
| --- | --- | --- |
| `want` | 想要 | `want to do`；`want someone to do` |
| `hope` | 希望 | `hope to do`；`hope that ...` |
| `expect` | 预料；期待 | `expect to do`；`expect someone to do` |
| `wish` | 希望；但愿 | `wish to do`；`wish that ...` |
| `prefer` | 更喜欢；宁愿 | `prefer to do`；`prefer one thing to another` |
| `decide` | 决定 | `decide to do`；`decide on something` |
| `choose` | 选择 | `choose to do`；`choose between two things` |
| `try` | 努力；尝试 | `try to do`；`try doing` |
| `plan` | 计划 | `plan to do`；`plan for something` |
| `agree` | 同意 | `agree with someone`；`agree to do` |


**语境例句**

- **want｜想要**：I **want** to understand how these words work in a sentence. → 我想理解这些词在句子中怎样发挥作用。

- **hope｜希望**：I **hope** we can finish before lunch. → 我希望我们能在午饭前完成。

- **expect｜预料；期待**：We **expect** the new room to be ready by Friday. → 我们预计新房间到星期五就能准备好。

- **wish｜希望；但愿**：I **wish** I had more time to read. → 要是我有更多时间读书就好了。

- **prefer｜更喜欢；宁愿**：I **prefer** short examples to long explanations. → 比起长篇解释，我更喜欢简短的例子。

- **decide｜决定**：

  - Let's **decide** on a time before we leave. → 离开前，我们把时间定下来吧。
  - We **decided** to wait until everyone had arrived. → 我们决定等到所有人都到了再开始。

- **choose｜选择**：You can **choose** to work alone or with a partner. → 你可以选择独自完成，也可以和同伴一起做。

- **try｜努力；尝试**：

  - I **tried** to open the file, but it wouldn't load. → 我努力想打开文件，但它加载不出来。
  - **Try** opening it in another browser; that might solve the problem. → 试试用另一个浏览器打开，也许能解决问题。

- **plan｜计划**：We **plan** to review these words again next week. → 我们计划下周再复习这些词。

- **agree｜同意**：I **agree** with your main point, but I have one question. → 我同意你的主要观点，但还有一个问题。

### 1.5 交流、说明与表达（10 词）

| 单词 | 核心义 | 常见搭配或句式 |
| --- | --- | --- |
| `say` | 说；表明 | `say something`；`say that ...` |
| `tell` | 告诉；吩咐 | `tell someone something`；`tell someone to do` |
| `speak` | 说话；谈及 | `speak to someone`；`speak about something` |

| `ask` | 问；请求 | `ask someone to do`；`ask for something` |

| `suggest` | 建议；暗示 | `suggest doing`；`suggest that ...` |

**语境例句**

- **say｜说；表明**：What did she **say** about the new plan? → 她是怎么评价新计划的？

- **tell｜告诉；吩咐**：

  - Please **tell** me if you need more time. → 如果需要更多时间，请告诉我。
  - She **told** us to wait outside. → 她让我们在外面等。

- **speak｜说话；谈及**：Could I **speak** to you after the meeting? → 开完会后，我能和你说几句话吗？

- **talk｜交谈；讨论**：Let's **talk** about the difficult part first. → 我们先谈谈比较难的部分吧。

- **ask｜问；请求**：

  - Don't be afraid to **ask** for help when you get stuck. → 遇到困难时，别怕寻求帮助。
  - I'll **ask** him to check the figures. → 我会请他核对这些数字。

- **answer｜回答；回应**：Could you **answer** the first question before we continue? → 继续之前，你能先回答第一个问题吗？

- **explain｜解释；说明**：Could you **explain** the difference to me using an example? → 你能用一个例子向我解释其中的区别吗？

- **show｜展示；表明**：

  - This sentence **shows** how the word is used in everyday conversation. → 这个句子展示了该词在日常对话中的用法。
  - Could you **show** me where to click? → 你能给我指一下该点哪里吗？

- **suggest｜建议；暗示**：I **suggest** taking a short break before we start again. → 我建议在重新开始前先休息一下。

- **describe｜描述**：How would you **describe** your usual working day? → 你会怎样描述自己平常一天的工作？

- **difficult｜困难的**：I find it **difficult** to understand the sentence without the previous paragraph. → 没有前面那一段，我觉得这个句子很难理解。

- **simple｜简单的**：There's a **simple** way to remember the difference. → 有一个简单的方法可以记住这个区别。

- **common｜常见的；共同的**：This is a **common** mistake among beginners. → 这是初学者常犯的错误。

- **general｜总体的；一般的**：Could you give me a **general** idea of how the system works? → 你能大致说说这个系统怎样运作吗？

- **particular｜特定的；特别的**：Is there a **particular** reason why you chose this example? → 你选择这个例子有什么特定的原因吗？

- **special｜特殊的**：Do I need a **special** tool, or will an ordinary pen do? → 我需要专门的工具，还是普通钢笔就行？

- **whole｜整个的**：Read the **whole** paragraph before you decide what the word means. → 先读完整段，再判断这个词是什么意思。

- **main｜主要的**：The **main** reason I chose this course is the speaking practice. → 我选择这门课的主要原因是它提供口语练习。

- **own｜自己的**：I'd like to try doing it on my **own** before asking for help. → 求助之前，我想先试着自己完成。

## 4. 通用或抽象名词（20 词）

### 4.1 通用指代、关系与抽象内容（20 词）

| 单词 | 核心义 | 常见搭配或句式 |
| --- | --- | --- |
| `thing` | 事情；东西；情况 | `a useful thing`；`the thing is that ...` |
| `way` | 方式；途径 | `a way to do`；`in this way` |
| `time` | 时间；次数 | `It takes time to do.`；`time to do` |
| `case` | 情况；例子 | `in this case`；`in case of ...` |
| `point` | 要点；阶段；观点 | `the point is that ...`；`at this point` |
| `part` | 部分；作用 | `part of ...`；`take part in ...` |
| `kind` | 种类 | `a kind of ...`；`what kind of ...?` |
| `sort` | 种类 | `a sort of ...`；`sort of ...` |
| `type` | 类型 | `a type of ...` |
| `fact` | 事实 | `in fact`；`the fact that ...` |
| `idea` | 想法；概念 | `have an idea`；`the idea of doing` |
| `reason` | 原因；理由 | `the reason why ...`；`a reason for ...` |
| `result` | 结果 | `as a result`；`the result of ...` |
| `problem` | 问题；困难 | `a problem with ...`；`solve a problem` |
| `question` | 问题；疑问 | `a question about ...`；`the question is whether ...` |
| `issue` | 问题；议题 | `an issue with ...`；`address an issue` |
| `matter` | 事情；问题 | `as a matter of fact`；`no matter what ...` |
| `situation` | 情况；处境 | `in this situation` |
| `purpose` | 目的 | `the purpose of ...`；`on purpose` |
| `effect` | 影响；效果 | `have an effect on ...`；`in effect` |

`own` 在本表的 `my own way` 中属于限定用法，不能把这一组中的所有词一律当成普通形容词。词性应结合具体句子判断。


**语境例句**

- **thing｜事情；东西；情况**：The important **thing** is to understand what the speaker means. → 重要的是理解说话人想表达什么。

- **way｜方式；途径**：Reading examples is a useful **way** to learn new words. → 阅读例句是学习新词的一个有用方法。

- **time｜时间；次数**：

  - It takes **time** to become comfortable with a new language. → 要逐渐适应一门新语言，需要时间。
  - I've read this paragraph three **times**, but I still have a question. → 这一段我已经读了三遍，但仍有一个疑问。

- **case｜情况；例子**：The answer depends on the context; in this **case**, “it” refers to the report. → 答案取决于语境，在这里 it 指的是那份报告。

- **point｜要点；阶段；观点**：

  - I understand the individual words, but I'm missing the main **point**. → 单个词我都认识，但还没抓住主要意思。
  - At this **point**, we need to stop and check the details. → 到了这个阶段，我们需要停下来检查细节。

- **part｜部分；作用**：

  - The final **part** of the lesson is a short conversation. → 这节课的最后一部分是一段简短对话。
  - Everyone has a **part** to play in the project. → 每个人都能在这个项目中发挥作用。

- **kind｜种类**：What **kind** of examples help you remember new words? → 什么类型的例句有助于你记住新词？

- **sort｜种类**：This **sort** of problem usually has a simple solution. → 这类问题通常有一个简单的解决办法。

- **type｜类型**：Choose the **type** of exercise that suits your level. → 选择适合你水平的练习类型。

- **fact｜事实**：The **fact** that we disagree doesn't mean either of us is careless. → 我们意见不一这一事实，并不意味着我们其中有人不认真。

- **idea｜想法；概念**：I like the **idea** of learning these words through a short story. → 我喜欢通过一个小故事来学习这些词的想法。

- **reason｜原因；理由**：The **reason** I was late is that I went to the wrong building. → 我迟到的原因是走错了楼。

- **result｜结果**：We changed the method; as a **result**, more people understood the lesson. → 我们改了方法，结果更多人理解了这节课。

- **problem｜问题；困难**：There's a **problem** with the link: it opens the wrong page. → 这个链接有个问题，它会打开错误的页面。

- **question｜问题；疑问**：I have a **question** about the difference between these two sentences. → 我有一个关于这两个句子区别的问题。

- **issue｜问题；议题**：We should address the **issue** of unclear instructions before adding more exercises. → 增加更多练习之前，我们应该先解决说明不清的问题。

- **matter｜事情；问题**：I'd like to discuss a private **matter** after the meeting. → 我想在会后谈一件私事。

- **situation｜情况；处境**：In this **situation**, asking one clear question may help. → 在这种情况下，提出一个明确的问题可能会有帮助。

- **purpose｜目的**：

  - The **purpose** of this example is to show the time relationship. → 这个例子的目的是展示时间关系。
  - I left the answer blank on **purpose** so we could discuss it. → 我是故意把答案留空的，好让我们讨论。

- **effect｜影响；效果**：Changing one small word can have a big **effect** on the meaning. → 改动一个小词可能对含义产生很大影响。

## 容易混淆的句式

| 句式 | 区别 |
| --- | --- |
| `remember to do` / `remember doing` | 前者是记得去做，后者是记得做过。 |
| `forget to do` / `forget doing` | 前者是忘记去做，后者是忘记做过。 |
| `try to do` / `try doing` | 前者强调努力完成，后者强调试一种方法。 |
| `stop doing` / `stop to do` | 前者是停止当前动作，后者是停下来去做另一件事。 |
| `used to do` / `be used to doing` / `be used for doing` | 分别表示过去常常做、习惯于做、被用于做。 |
| `suggest doing` | 表示建议做某事，避免误用成 `suggest someone to do`。 |
| `explain something to someone` | 表示向某人解释某事，避免误用成 `explain someone something`。 |


**对照例句：先看事情有没有发生，以及动作之间是什么关系**

- **remember to do / remember doing**：

  - Please **remember to send** the file before you leave. → 离开前，请记得发送文件。——先记住要做，再去做。
  - I **remember sending** the file yesterday. → 我记得昨天发过文件。——回忆已经做过的事。

- **forget to do / forget doing**：

  - I **forgot to call** Mia, so I sent her a message instead. → 我忘了给米娅打电话，于是改发了消息。——该做的事没有做。
  - I'll never **forget hearing** her first speech. → 我永远不会忘记听她第一次演讲的情景。——不忘记已经经历过的事；forget doing 常见于这类否定表达。

- **try to do / try doing**：

  - I **tried to open** the window, but it was stuck. → 我努力想打开窗户，但它卡住了。——强调努力或尝试完成。
  - It's hot here. **Try opening** the window. → 这里很热，试试开窗。——把某种做法当作可能的解决方法。

- **stop doing / stop to do**：

  - We **stopped talking** when the meeting began. → 会议开始时，我们停止了说话。——停止 talking 这个动作。
  - We were walking home when we **stopped to talk** to a neighbour. → 我们正走着回家，中途停下来和邻居说话。——停下走路，去做 talk 这件事。

- **used to do / be used to doing / be used for doing**：

  - I **used to work** at night, but now I work during the day. → 我过去经常晚上工作，现在改在白天工作。——过去的习惯。
  - I **am used to working** at night, so it doesn't bother me. → 我习惯了晚上工作，所以不觉得困扰。——to 是介词，后接 working。
  - This room **is used for holding** small meetings. → 这个房间用于召开小型会议。——说明用途。

- **suggest doing**：

  - She **suggested meeting** after lunch. → 她建议午饭后见面。——suggest 后直接接 doing；若要引出建议由谁做，可用 suggest that… 等结构。

- **explain something to someone**：

  - Could you **explain the plan to me** before we start? → 开始前，你能向我解释一下这个计划吗？——计划是被解释的内容，me 是接受解释的人。

- **mean doing / mean to do**：

  - Leaving now will **mean missing** lunch. → 现在出发就意味着吃不上午饭。——说明结果或代价。
  - I **meant to call** you, but I forgot. → 我本来打算给你打电话，但忘了。——说明意图。

本表是第一批学习清单，不是高频通用词的穷尽集合。熟悉这些词后，应优先积累它们在阅读材料中的新搭配。

例句为学习用原创内容；易混句式的用法可参见 [Cambridge：动词后接不定式或 -ing 的意义差别](https://dictionary.cambridge.org/us/grammar/british-grammar/infinitive-or-verb-ing)、[British Council：remember、forget、try、stop 的用法](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/verbs-followed-ing-or-infinitive-change-meaning)。
