## 1. 助动词

| 细分类别 | 单词 |
| --- | --- |
| 基本助动词 | be, have, do |
| 核心情态动词 | can, could, may, might, must, shall, should, will, would |

`be`、`have`、`do` 在不同句子中也可以作主要动词；具体词形见第 10 节。


**语境例句**

**基本助动词**

- **be｜构成进行时**：I'll **be** waiting outside when you arrive. → 你到的时候，我会在外面等你。
- **have｜构成完成时**：I **have** already checked the address, so we can leave. → 我已经核对过地址了，所以我们可以出发。
- **do｜帮助构成疑问句**：**Do** you understand why she left early? → 你明白她为什么提前离开吗？

**核心情态动词**

- **can｜能力；能够**：I **can** explain it with an example. → 我能用一个例子解释它。
- **could｜委婉请求**：**Could** you give me a little more time? → 你能再给我一点时间吗？
- **may｜可能**：She **may** be on the train, so she hasn't replied yet. → 她可能在火车上，所以还没有回复。
- **might｜不确定的可能性**：We **might** finish today, but I can't promise. → 我们也许今天能完成，但我不能保证。
- **must｜必须**：The last bus leaves at six; we **must** leave now. → 末班车六点发车，我们现在必须走了。
- **shall｜用 Shall we… 提议**：**Shall** we discuss the first question together? → 我们一起讨论第一个问题，好吗？
- **should｜建议；应该**：You **should** read the whole paragraph before translating it. → 翻译前，你应该读完整段。
- **will｜对将来作出承诺**：I **will** send you the notes tonight. → 我今晚会把笔记发给你。
- **would｜设想情况下会做**：If I had more time, I **would** read the report again. → 如果我有更多时间，我会再读一遍报告。

**同一个情态动词的其他常见语境**

- **can｜询问是否被允许**：**Can** I use your desk for a few minutes? → 我可以用你的书桌几分钟吗？
- **could｜过去的一般能力**：When I was at school, I **could** read quickly but often missed details. → 我上学时读得很快，但经常漏掉细节。
- **could｜对现在情况的可能性判断**：That noise **could** be the printer in the next room. → 那声音可能是隔壁的打印机发出的。
- **may｜较礼貌地请求许可**：**May** I ask one more question? → 我可以再问一个问题吗？
- **must｜根据线索作出较有把握的推断**：I can hear voices inside; someone **must** be at home. → 我能听见里面有人说话，一定有人在家。
- **should｜根据情况作出预期**：She left an hour ago, so she **should** be here soon. → 她一小时前就出发了，应该很快就到这里了。
- **will｜对接下来情况的预测**：If you look on the first page, you **will** find a summary. → 你看第一页，就会找到一段总结。
- **would｜委婉请求，不表示过去时间**：**Would** you send me the latest version, please? → 请你把最新版本发给我，好吗？
- **would｜有过去语境时，表示反复发生的动作**：When we were at school, we **would** read aloud every morning. → 上学时，我们每天早上都会大声朗读。

## 2. 冠词

| 细分类别 | 单词 |
| --- | --- |
| 定冠词 | the |
| 不定冠词 | a, an |


**语境例句**

**冠词：第一次提到与再次指认**

- **the｜双方知道或前文提过的特定对象**：I received an email this morning. **The** email was from my teacher. → 今天早上我收到一封邮件，这封邮件是老师发来的。
- **a｜首次引入一个可数对象**：I need **a** pen to fill in this form. → 我需要一支笔来填这张表。
- **an｜后接以元音音素开头的词**：We waited for **an** hour before the train arrived. → 我们等了一个小时，火车才到。

## 3. 代词

### 3.1 基本分类

| 细分类别 | 单词或短语 |
| --- | --- |
| 人称主格 | I, you, he, she, it, we, they |
| 人称宾格 | me, you, him, her, it, us, them |
| 名词性物主代词 | mine, yours, his, hers, ours, theirs |
| 反身代词 | myself, yourself, himself, herself, itself, ourselves, yourselves, themselves |
| 相互代词 | each other, one another |
| 疑问代词 | who, whom, whose, what, which |
| 关系代词 | who, whom, whose, which, that |


**语境例句**

**人称主格：谁做这件事**

- **I｜我，作主语**：**I** saved the file before lunch. → 我在午饭前保存了文件。
- **you｜你或你们，作主语**：**You** can ask another question if anything is unclear. → 如果还有不清楚的地方，你可以再问一个问题。
- **he｜他，作主语**：Tom is checking the figures. **He** will reply later. → 汤姆正在核对数字，他晚些时候会回复。
- **she｜她，作主语**：Mia knows the answer. **She** explained it yesterday. → 米娅知道答案，她昨天解释过。
- **it｜它，指前面提过的事物**：I opened the file, but **it** was empty. → 我打开了文件，但文件是空的。
- **we｜我们，作主语**：**We** need to agree on a time before we leave. → 我们离开前需要商定一个时间。
- **they｜他们或它们，作主语**：The instructions are new. **They** are easier to follow. → 这些说明是新的，比以前更容易照着做。

**人称宾格：动作指向谁**

- **me｜我，作宾语**：Could you send **me** the address? → 你能把地址发给我吗？
- **you｜你或你们，作宾语**：I'll call **you** when the meeting ends. → 会议结束后我会给你打电话。
- **him｜他，作宾语**：Tom missed the first part, so I explained it to **him**. → 汤姆错过了第一部分，所以我向他解释了一遍。
- **her｜她，作宾语**：Mia is outside. Please ask **her** to come in. → 米娅在外面，请让她进来。
- **it｜它，作宾语**：This sentence is difficult. Could you explain **it**? → 这个句子很难，你能解释一下吗？
- **us｜我们，作宾语**：The teacher gave **us** a clear example. → 老师给了我们一个清楚的例子。
- **them｜他们或它们，作宾语**：These notes are useful. Please keep **them**. → 这些笔记很有用，请保留它们。

**名词性物主代词：独立表示谁的**

- **mine｜我的，后面不再接被替代的名词**：Your bag is black; **mine** is blue. → 你的包是黑色的，我的是蓝色的。
- **yours｜你的或你们的**：This seat is **yours**; I'll sit by the window. → 这个座位是你的，我坐窗边。
- **his｜他的**：My answer is short, but **his** is much more detailed. → 我的答案很短，但他的详细得多。
- **hers｜她的**：My desk is near the door; **hers** is by the window. → 我的书桌靠近门，她的在窗边。
- **ours｜我们的**：Their team finished first; **ours** finished second. → 他们队最先完成，我们队第二个完成。
- **theirs｜他们的**：Our room is small, but **theirs** is even smaller. → 我们的房间很小，但他们的更小。

**反身代词：动作回到主语自己**

- **myself｜我自己**：I taught **myself** how to use the program. → 我自学了怎样使用这个程序。
- **yourself｜你自己**：Give **yourself** a little time to think. → 给自己一点时间想想。
- **himself｜他自己**：Tom checked the address **himself** before leaving. → 汤姆出发前亲自核对了地址。
- **herself｜她自己**：Mia introduced **herself** before the discussion began. → 讨论开始前，米娅作了自我介绍。
- **itself｜它自己**：The door closed by **itself**. → 门自己关上了。
- **ourselves｜我们自己**：We need to ask **ourselves** why the first plan failed. → 我们需要问问自己，第一个计划为什么失败了。
- **yourselves｜你们自己**：You two can help **yourselves** to some tea. → 你们俩可以自己倒些茶喝。
- **themselves｜他们自己**：The students organised the meeting **themselves**. → 学生们自己组织了这次会议。

**相互代词：双方彼此**

- **each other｜彼此**：We check **each other's** work before handing it in. → 交作业前，我们互相检查对方的作业。
- **one another｜互相**：The team members listened to **one another** patiently. → 团队成员耐心地倾听彼此的意见。

**疑问代词：直接询问人或事物**

- **who｜谁，询问人物**：**Who** wrote this note? → 这张便条是谁写的？
- **whom｜谁，较正式的宾格**：To **whom** should I send the completed form? → 我应该把填好的表格发给谁？（较正式）
- **whose｜谁的，询问归属**：This notebook has no name on it. **Whose** is it? → 这个笔记本没写名字，它是谁的？
- **what｜什么**：**What** happened after I left? → 我离开后发生了什么？
- **which｜哪一个，从已知范围中选择**：There are two routes. **Which** would you prefer? → 有两条路线，你更想选哪一条？

**关系代词：给前面的名词补充信息**

- **who｜指人，在从句中作主语**：The person **who** called you is waiting outside. → 刚才给你打电话的那个人正在外面等。
- **whom｜指人，在从句中作宾语，较正式**：The colleague **whom** I spoke to has sent the notes. → 和我谈过话的那位同事已经把笔记发来了。
- **whose｜表示所属关系**：I met a student **whose** brother works here. → 我遇到一名学生，他的哥哥在这里工作。
- **which｜指物，在从句中作主语**：The file, **which** contains our notes, is on the desktop. → 那份文件在桌面上，里面有我们的笔记。
- **that｜指物，在从句中作宾语**：The example **that** you gave me was helpful. → 你给我的那个例子很有帮助。

### 3.2 不定代词：复合形式

下面列全常见的 `some-`、`any-`、`every-`、`no-` 与 `-one`、`-body`、`-thing` 的组合，共 12 项。

| 含义 | 指人：-one | 指人：-body | 指事物：-thing |
| --- | --- | --- | --- |
| 某个、一些 | someone | somebody | something |
| 任何一个 | anyone | anybody | anything |
| 每个、全部 | everyone | everybody | everything |
| 没有一个 | no one | nobody | nothing |

`no one` 通常写作两个词，也可写作 `no-one`；其余表内形式连写。这组不定代词作主语时，通常使用单数谓语动词。参见 [Cambridge：复合不定代词](https://dictionary.cambridge.org/us/grammar/british-grammar/pronouns-indefinite-body-one)。


**语境例句**

**复合不定代词：人物或事物尚未具体指明**

- **someone｜某人**：**Someone** left a note on my desk, but I don't know who. → 有人在我的桌上留了张便条，但我不知道是谁。
- **somebody｜某人，与 someone 意义接近**：**Somebody** is knocking at the door. Could you check? → 有人在敲门，你能看看吗？
- **something｜某件事或某样东西**：I need to tell you **something** before the meeting. → 开会前我需要告诉你一件事。
- **anyone｜任何人**：Can **anyone** explain the last sentence? → 有人能解释最后一句吗？
- **anybody｜任何人，与 anyone 意义接近**：Is **anybody** still working in the office? → 办公室里还有人在工作吗？
- **anything｜任何事情或东西**：Is there **anything** you want to change? → 有什么是你想改动的吗？
- **everyone｜每个人，作主语时通常接单数谓语**：**Everyone** has a copy, so we can start. → 每个人都有一份了，所以我们可以开始。
- **everybody｜每个人，与 everyone 意义接近**：**Everybody** is ready except Tom. → 除了汤姆，大家都准备好了。
- **everything｜所有事情或东西**：I've checked **everything** on the list. → 我已经检查了清单上的所有事项。
- **no one｜没有人**：**No one** knows why the meeting was cancelled. → 没有人知道会议为什么取消了。
- **nobody｜没有人，与 no one 意义接近**：**Nobody** was in the room when I arrived. → 我到的时候，房间里没有人。
- **nothing｜没有任何事情或东西**：There was **nothing** in the envelope. → 信封里什么也没有。

### 3.3 不定代词：其他常见形式

下面按传统教学语法列出可独立使用的形式；现代语法也可能把其中一些分析为独立使用的限定词。

| 细分类别 | 单词或短语 |
| --- | --- |
| 泛指个体或替代前文名词 | one, ones |
| 全体、两者、分配或否定 | all, both, each, either, neither, none |
| 不确定数量 | some, any, many, much, few, little, several, enough |
| 数量比较 | more, most, fewer, fewest, less, least |
| 另一个、其他 | another, other, others, the other, the others |
| 可独立使用的数量短语 | a few, a little, a lot, lots, plenty |

注意：`every` 不能像 `each` 一样直接独立作代词；表示“一个也没有”时，独立形式通常用 `none`，而不是 `no`。数量表达作限定词和代词的区别，参见 [Cambridge：数量词](https://dictionary.cambridge.org/us/grammar/british-grammar/quantifiers)。


**语境例句**

**泛指或替代前文名词**

- **one｜一个；替代前面出现的单数可数名词**：I need a pen. Do you have **one** I can borrow? → 我需要一支笔，你有一支可以借给我的吗？
- **ones｜替代前面出现的复数可数名词**：These examples are useful. Let's write some similar **ones**. → 这些例子很有用，我们写几个类似的吧。

**全体、两者、分配或否定**

- **all｜全部，独立使用**：The seats were free at nine. Now **all** are taken. → 九点时座位都空着，现在全被占了。
- **both｜两个都，独立使用**：I tried two methods. **Both** worked. → 我试了两种方法，两种都有效。
- **each｜每一个，独立使用**：There are four students. **Each** has a copy. → 有四名学生，每人都有一份。
- **either｜两者中任意一个，独立使用**：We can meet on Tuesday or Thursday. **Either** is fine with me. → 我们可以周二或周四见面，哪个时间我都可以。
- **neither｜两个都不，独立使用**：I checked two dates. **Neither** works for Mia. → 我查了两个日期，米娅这两天都不方便。
- **none｜一个也没有；没有任何数量**：I tried three keys, but **none** worked. → 我试了三把钥匙，但一把也打不开。

**不确定数量：后面的名词可以根据前文省略**

- **some｜一些，独立使用**：I've made some tea. Would you like **some**? → 我泡了些茶，你想喝一点吗？
- **any｜任何数量，常见于疑问或否定语境**：We need more paper, but we don't have **any**. → 我们需要更多纸，但现在一点也没有了。
- **many｜许多，所指对象可数**：I invited ten people, but not **many** came. → 我邀请了十个人，但来的人不多。
- **much｜许多，所指内容不可数**：There was a lot of work to do. We didn't finish **much**. → 有很多工作要做，我们完成的并不多。
- **few｜很少，强调数量不足**：Many people applied, but **few** were chosen. → 很多人申请，但获选的人很少。
- **little｜很少，强调数量不足**：She told me a great deal, but I remember **little**. → 她告诉了我很多，但我记得的很少。
- **several｜几个，独立使用**：I expected one reply, but **several** arrived this morning. → 我原以为只会收到一份回复，但今天早上收到了好几份。
- **enough｜足够的数量，独立使用**：We don't need more chairs; we have **enough**. → 我们不需要更多椅子了，现有的已经够了。

**数量比较：比较对象由前文给出**

- **more｜更多，独立使用**：I've checked five files. How many **more** need checking? → 我已经检查了五个文件，还有多少需要检查？
- **most｜大多数，独立使用**：There were nine books on the list, and I read **most**. → 清单上有九本书，其中大多数我都读过。
- **fewer｜更少，替代可数名词复数**：Ten people came last week, but **fewer** came today. → 上周来了十个人，今天来的人更少。
- **fewest｜最少，替代可数名词复数**：We counted everyone's mistakes. Mia made the **fewest**. → 我们数了每个人的错误，米娅犯得最少。
- **less｜更少，替代不可数的内容**：I expected a lot of help, but I received **less** than I hoped. → 我原本期待很多帮助，但得到的比希望的少。
- **least｜最少，替代不可数的内容**：We all paid different amounts. Tom paid the **least**. → 我们支付的金额各不相同，汤姆付得最少。

**另一个与其他对象：留意范围是否已经明确**

- **another｜另外一个**：This example is unclear. Could you give me **another**? → 这个例子不清楚，你能再给我一个吗？
- **other｜另一个，单数独立使用通常需 the 等限定词**：There are two doors. One is locked; the **other** is open. → 有两扇门，一扇锁着，另一扇开着。
- **others｜其他一些，未必是剩下的全部**：Some students work alone; **others** prefer a partner. → 有些学生独自学习，另一些更喜欢找个同伴。
- **the other｜两个之中剩下的那个**：I have two keys. This one is for home; **the other** is for the office. → 我有两把钥匙，这把是家里的，另一把是办公室的。
- **the others｜已知范围内剩下的全部**：Five people came. One left early; **the others** stayed. → 来了五个人，一个提前走了，其余的人都留下了。

**可独立使用的数量短语**

- **a few｜几个，表示有一些**：Most seats are taken, but **a few** are still free. → 大多数座位被占了，但还有几个空位。
- **a little｜一点，表示还有一些**：There isn't much tea left, but we have **a little**. → 剩下的茶不多，但我们还有一点。
- **a lot｜大量，名词根据前文省略**：I expected three replies, but I received **a lot**. → 我原以为会有三份回复，结果收到了很多。
- **lots｜很多，较口语**：“Do you have any questions?” “Yes, I have **lots**.” → “你有问题吗？”“有，我有很多问题。”
- **plenty｜足够而且有余**：We need some chairs. Don't worry; we have **plenty**. → 我们需要一些椅子，别担心，我们有的是。

### 3.4 相关地点表达

| 某处 | 任何地方 | 每个地方 | 没有任何地方 |
| --- | --- | --- | --- |
| somewhere | anywhere | everywhere | nowhere |

这组形式与复合不定代词构词相似，常在学习语法中另称“不定副词”；它们不能在所有句型中直接替换指人或指物的代词。


**语境例句**

**地点表达**

- **somewhere｜某个地方**：I've put the note **somewhere**, but I can't remember where. → 我把便条放在某个地方了，但想不起在哪儿。
- **anywhere｜任何地方**：You can sit **anywhere** you like. → 你可以坐在任何喜欢的位置。
- **everywhere｜到处**：I looked **everywhere**, but I couldn't find the key. → 我到处都找了，还是找不到钥匙。
- **nowhere｜无处；没有地方**：The café was full, so there was **nowhere** to sit. → 咖啡馆坐满了，所以没有地方可坐。

## 4. 限定词

### 4.1 基本分类

| 细分类别 | 单词 |
| --- | --- |
| 指示限定词 | this, that, these, those |
| 形容词性物主限定词 | my, your, his, her, its, our, their |
| 分配限定词 | each, every, either, neither |


**语境例句**

**指示限定词：后面直接接名词**

- **this｜这个，通常指较近的对象**：**This** paragraph explains the problem we discussed. → 这一段解释了我们讨论过的问题。
- **that｜那个，通常指较远或先前提到的对象**：Do you remember **that** question from yesterday? → 你还记得昨天那个问题吗？
- **these｜这些，后接复数名词**：**These** examples all use the same structure. → 这些例子都用了同一个结构。
- **those｜那些，后接复数名词**：Please put **those** books back on the shelf. → 请把那些书放回架子上。

**形容词性物主限定词：后面保留名词**

- **my｜我的，后面接名词**：I left **my** notebook in the office. → 我把我的笔记本落在办公室了。
- **your｜你的或你们的，后面接名词**：Please write **your** name at the top. → 请在上方写下你的名字。
- **his｜他的，后面接名词**：Tom sent **his** answer before lunch. → 汤姆午饭前发来了他的答案。
- **her｜她的，后面接名词**：Mia checked **her** notes before speaking. → 米娅发言前看了看自己的笔记。
- **its｜它的，后面接名词**：The program has changed **its** layout. → 这个程序改变了它的布局。
- **our｜我们的，后面接名词**：**Our** meeting starts in ten minutes. → 我们的会议十分钟后开始。
- **their｜他们的，后面接名词**：The students have handed in **their** work. → 学生们已经交了他们的作业。

**分配限定词：明确分配范围**

- **each｜各个，强调逐个看待**：**Each** student gets a different question. → 每个学生拿到的问题各不相同。
- **every｜每个，强调范围内全部**：I read English **every** day before breakfast. → 我每天早餐前都读英语。
- **either｜两者中的任意一个，后接单数名词**：I've marked two routes. You can take **either** route. → 我标出了两条路线，你任选一条都可以。
- **neither｜两个都不，后接单数名词**：I tried both keys. **Neither** key worked. → 我试了两把钥匙，两把都打不开。

### 4.2 数量限定词及其常见组合

| 使用范围 | 单词或短语 |
| --- | --- |
| 复数可数名词 | many, few, a few, several, fewer, fewest |
| 不可数名词 | much, little, a little, less, least |
| 复数可数名词或不可数名词 | some, any, no, all, enough, more, most |
| 两个对象 | both |

`fewest`、`least` 表示最高级时通常与 `the` 连用；`any`、`no` 也可以放在单数可数名词前，例如 `any question`、`no problem`。


**语境例句**

**修饰复数可数名词**

- **many｜许多**：There are **many** ways to explain the same idea. → 同一个想法有许多解释方式。
- **few｜很少，强调不够多**：**Few** people came, so we postponed the decision. → 来的人很少，所以我们推迟了决定。
- **a few｜有几个，强调还有一些**：**A few** people offered to help, so I wasn't alone. → 有几个人主动帮忙，所以我不是一个人在做。
- **several｜几个**：We discussed **several** possible solutions. → 我们讨论了几个可能的解决方案。
- **fewer｜比以前或比较对象少**：This version has **fewer** mistakes than the first one. → 这个版本的错误比第一个版本少。
- **fewest｜数量最少**：Of the three answers, hers had the **fewest** errors. → 在三份答案中，她的错误最少。

**修饰不可数名词**

- **much｜大量，常用于疑问或否定句**：How **much** time do we have before lunch? → 午饭前我们还有多少时间？
- **little｜很少，强调不足**：We have **little** time, so keep the explanation short. → 我们的时间很少，所以解释简短些。
- **a little｜有一点，强调还有一些**：We have **a little** time; let's look at one more example. → 我们还有一点时间，再看一个例子吧。
- **less｜更少**：This method takes **less** time than the old one. → 这种方法比以前的方法耗时更少。
- **least｜最少**：This option requires the **least** effort. → 这个选项需要付出的精力最少。

**两类名词都可以修饰的数量词**

- **some｜一些**：We've made **some** progress since last week. → 从上周以来，我们已经取得了一些进展。
- **any｜任何；疑问或否定语境中的一些**：Do you have **any** questions about this example? → 关于这个例子，你有什么问题吗？
- **no｜没有，后面仍接名词**：There's **no** reason to rush; we have enough time. → 没有必要着急，我们的时间够用。
- **all｜全部**：**All** the files are ready to send. → 所有文件都准备好可以发送了。
- **enough｜足够的**：We don't have **enough** information to decide yet. → 我们目前还没有足够的信息作决定。
- **more｜更多**：We need **more** examples of everyday conversation. → 我们需要更多日常对话的例子。
- **most｜大多数**：**Most** students found the final question useful. → 大多数学生觉得最后一个问题很有用。

**两个对象**

- **both｜两个都，后面接复数名词**：**Both** options are possible, so choose the one you prefer. → 两个选项都可行，所以选你更喜欢的那个吧。

### 4.3 常见数量短语

| 使用范围 | 短语 |
| --- | --- |
| 复数可数名词 | a number of, a large number of, a great many, a good many, a couple of |
| 不可数名词 | a bit of, a great deal of, a good deal of, a large amount of |
| 复数可数名词或不可数名词 | a lot of, lots of, plenty of |

数量短语可以继续通过修饰语扩展，因此这里列出常见固定形式。`a lot of`、`lots of`、`plenty of` 后接名词；名词省略时通常用 `a lot`、`lots`、`plenty`。参见 [Cambridge：lots、a lot、plenty](https://dictionary.cambridge.org/grammar/british-grammar/a-lot-lots)。


**语境例句**

**接复数可数名词的数量短语**

- **a number of｜一些；若干**：**A number of** students asked for more examples. → 一些学生要求增加例句。
- **a large number of｜大量**：**A large number of** files need checking before Friday. → 星期五之前有大量文件需要检查。
- **a great many｜很多**：I've heard **a great many** useful ideas today. → 今天我听到了很多有用的想法。
- **a good many｜相当多**：**A good many** people chose the evening class. → 相当多的人选择了晚课。
- **a couple of｜两个；口语中也可指少数几个**：We still have **a couple of** questions to discuss. → 我们还有几个问题要讨论。

**接不可数名词的数量短语**

- **a bit of｜一点**：Could you give me **a bit of** advice? → 你能给我一点建议吗？
- **a great deal of｜大量**：Preparing this course took **a great deal of** time. → 准备这门课程花了很多时间。
- **a good deal of｜相当多**：We've made **a good deal of** progress this month. → 我们这个月取得了相当大的进展。
- **a large amount of｜大量**：The task involves **a large amount of** information. → 这项任务涉及大量信息。

**两类名词都可接的数量短语**

- **a lot of｜很多**：We have **a lot of** work to do before lunch. → 午饭前我们有很多工作要做。
- **lots of｜很多，较口语**：There are **lots of** useful examples in this book. → 这本书里有很多有用的例子。
- **plenty of｜充足的；很多**：There's **plenty of** time to ask questions after the talk. → 讲话结束后，有充足的时间提问。

## 5. 连词

### 5.1 并列连词

| 细分类别 | 单词 |
| --- | --- |
| 常见并列连词 | and, but, or, nor, for, yet, so |

常见成对连接结构：`both ... and ...`、`either ... or ...`、`neither ... nor ...`、`not only ... but also ...`。


**语境例句**

**并列连词：连接地位相同的成分**

- **and｜并列或顺承**：I read the note **and** checked the address. → 我读了便条，然后核对了地址。
- **but｜转折**：I know the words, **but** I don't understand the sentence. → 这些词我都认识，但我不理解这个句子。
- **or｜选择**：Would you like to meet online **or** in person? → 你想在线见面，还是当面见面？
- **nor｜在否定后补充另一否定，常有倒装**：He didn't reply, **nor** did he call. → 他没有回复，也没有打电话。
- **for｜说明原因，较书面**：We turned back, **for** the road was blocked. → 我们往回走了，因为道路被堵住了。
- **yet｜转折，表示出乎意料**：The explanation was long, **yet** it still missed the point. → 解释很长，却仍然没讲到重点。
- **so｜前面是原因，后面是结果**：The room was full, **so** we waited outside. → 房间里坐满了人，所以我们在外面等。

**正文提到的成对结构**

- **both ... and ...｜两者都，连接平行成分**：**Both** the question **and** the answer are on this page. → 问题和答案都在这一页上。
- **either ... or ...｜要么……要么……**：We can meet **either** before lunch **or** after work. → 我们可以在午饭前或下班后见面。
- **neither ... nor ...｜既不……也不……**：She was **neither** angry **nor** upset; she just needed time. → 她既没生气，也没难过，只是需要一点时间。
- **not only ... but also ...｜不仅……而且……**：This lesson is **not only** useful **but also** enjoyable. → 这节课不仅有用，而且很有趣。

### 5.2 从属连词及常见从句连接结构

以下按连接功能归类；同一个形式可能在不同语境下出现在多个类别中。`where`、`when`、`how` 在疑问从句和关系从句中还可能按连接副词或关系副词分析。

| 连接功能 | 单词或固定结构 |
| --- | --- |
| 时间 | after, before, when, whenever, while, whilst, as, since, until, till, once, as soon as, as long as, so long as, by the time |
| 原因、理由 | because, since, as, now that, seeing that, considering that, given that, in that |
| 条件 | if, unless, provided that, providing that, as long as, so long as, on condition that, assuming that, supposing that, suppose that |
| 预防、以防 | in case, lest, for fear that |
| 让步 | although, though, even though, even if, whether ... or ... |
| 对照 | whereas, while, whilst |
| 目的 | so that, in order that |
| 结果 | so, so that, so ... that ..., such ... that ... |
| 方式、假设比较 | as, as if, as though |
| 程度比较 | than, as ... as ..., not as ... as ..., not so ... as ... |
| 地点 | where, wherever |
| 陈述内容、是否 | that, if, whether |
| 例外、补充限制 | except that, save that |

`provided that`、`providing that`、`assuming that`、`supposing that`、`suppose that`、`seeing that`、`considering that` 中的 `that` 在相应用法中可以省略。`lest`、`save that` 较正式。

`however`、`therefore`、`moreover`、`nevertheless` 属于连接副词，不应直接当作并列连词使用。参见 [Cambridge：连词及其位置](https://dictionary.cambridge.org/grammar/british-grammar/subordinating-conjunctions)、[原因、结果和目的连接表达](https://dictionary.cambridge.org/grammar/british-grammar/conjunctions-causes-reasons-results-and-purpose)。


**语境例句**

**时间：把一件事放在另一件事之前、之后或同时**

- **after｜在某事发生之后**：I'll call you **after** I finish the report. → 我写完报告后给你打电话。
- **before｜在某事发生之前**：Save the file **before** you close the program. → 关闭程序前先保存文件。
- **when｜当……时**：I was reading **when** you called. → 你打电话来的时候，我正在看书。
- **whenever｜每当；无论何时**：Ask me **whenever** you need help. → 你什么时候需要帮助，都可以问我。
- **while｜在……期间，强调一段时间**：I took notes **while** she explained the process. → 她解释流程时，我做了笔记。
- **whilst｜在……期间，常见于英式英语**：Please keep quiet **whilst** the recording is playing. → 播放录音期间，请保持安静。
- **as｜正当……时，伴随发生**：**As** we were leaving, the phone rang. → 正当我们要离开时，电话响了。
- **since｜自从某事发生以来**：I haven't seen her **since** she changed jobs. → 自从她换工作以来，我就没见过她。
- **until｜一直到某事发生为止**：Wait **until** everyone is ready. → 等到大家都准备好。
- **till｜直到，与 until 意义接近**：I'll stay here **till** you come back. → 我会一直待在这里，直到你回来。
- **once｜一旦某事完成或成立**：**Once** you've checked the figures, send me the report. → 一旦核对完数字，就把报告发给我。
- **as soon as｜一……就……**：I'll tell you **as soon as** I hear anything. → 我一有消息就告诉你。
- **as long as｜持续整个……期间**：I'll keep this note **as long as** I live. → 我会一辈子保留这张便条。
- **so long as｜在所述情况持续期间，也带条件意味**：The lamp stayed on **so long as** anyone was working. → 只要还有人在工作，灯就一直亮着。
- **by the time｜到……的时候，先前动作已完成**：**By the time** we reached the café, it had closed. → 等我们到咖啡馆时，它已经关门了。

**原因：说明为什么**

- **because｜因为**：I asked again **because** I hadn't understood the first answer. → 我又问了一遍，因为没有听懂第一个答案。
- **since｜既然，提出已知或认可的原因**：**Since** everyone is here, let's begin. → 既然大家都到了，我们开始吧。
- **as｜由于；既然**：**As** you've finished the first part, you can take a break. → 既然你完成了第一部分，就可以休息一下。
- **now that｜既然现在已经……**：**Now that** we have the correct address, we can leave. → 现在既然有了正确地址，我们就可以出发。
- **seeing that｜鉴于，较口语**：**Seeing that** the train is late, let's get a coffee. → 既然火车晚点了，我们去喝杯咖啡吧。
- **considering that｜考虑到某个事实**：**Considering that** she had only one day, she did very well. → 考虑到她只有一天时间，她做得很好。
- **given that｜鉴于某个已知情况**：**Given that** time is short, let's focus on one example. → 鉴于时间有限，我们集中看一个例子吧。
- **in that｜在于……；因为具有所述特点**：This example differs from the first **in that** it refers to the past. → 这个例子与第一个不同之处在于，它说的是过去。

**条件：什么情况下成立**

- **if｜如果**：**If** you're free after lunch, we can discuss it then. → 如果你午饭后有空，我们到时候可以讨论。
- **unless｜除非；如果不**：I won't change the plan **unless** you agree. → 除非你同意，否则我不会改计划。
- **provided that｜只要，提出条件**：You can use the car **provided that** you return it by six. → 只要六点前还车，你就可以用。
- **providing that｜只要，与 provided that 意义接近**：We can meet outside **providing that** the weather stays dry. → 只要天气保持晴好，我们就可以在外面见面。
- **as long as｜只要**：You can borrow the book **as long as** you return it next week. → 只要下周归还，你就可以借这本书。
- **so long as｜只要**：I'm happy to wait **so long as** you tell me how long it will take. → 只要你告诉我要多久，我愿意等。
- **on condition that｜条件是，较正式**：She agreed to help **on condition that** we gave her enough time. → 她同意帮忙，条件是我们给她足够的时间。
- **assuming that｜假定**：**Assuming that** the train is on time, we'll arrive at five. → 假定火车准点，我们五点到达。
- **supposing that｜假设，引导设想**：**Supposing that** nobody comes, what shall we do? → 假如谁都不来，我们怎么办？
- **suppose that｜假设，引导听者设想**：**Suppose that** you had an extra hour. How would you use it? → 假设你多出一个小时，你会怎么利用？

**预防：为了防止可能出现的情况**

- **in case｜以防，提前作准备**：Take a jacket **in case** it gets cold. → 带件外套，以防天气变冷。
- **lest｜以免，较正式**：She wrote the code down **lest** she forget it. → 她把代码记下来，以免忘记。
- **for fear that｜唯恐；担心某事发生**：I saved a second copy **for fear that** the file might get damaged. → 我又存了一份，唯恐文件损坏。

**让步：承认一个情况，仍保留后面的结论**

- **although｜虽然**：**Although** I was tired, I finished the final paragraph. → 虽然很累，我还是写完了最后一段。
- **though｜虽然，与 although 意义接近**：**Though** the room was small, it was comfortable. → 虽然房间很小，但很舒适。
- **even though｜尽管，通常引出已成立的事实**：She joined the discussion **even though** she had little experience. → 尽管经验很少，她还是参加了讨论。
- **even if｜即使，常提出假设情况**：I'll attend the meeting **even if** I have to walk there. → 即使必须走着去，我也会参加会议。
- **whether ... or ...｜无论……还是……**：I'll call you **whether** I have good news **or** bad news. → 无论有好消息还是坏消息，我都会给你打电话。

**对照：把两种情况放在一起比较**

- **whereas｜而；相比之下**：I prefer short examples, **whereas** Tom likes long explanations. → 我喜欢简短的例子，而汤姆喜欢长篇解释。
- **while｜而，用于对照**：I work best in the morning, **while** Mia prefers evenings. → 我上午工作效率最高，而米娅更喜欢晚上。
- **whilst｜而，用于对照，常见于英式英语**：The first answer is clear, **whilst** the second is more detailed. → 第一个答案清楚，而第二个更详细。

**目的：为了达到什么目标**

- **so that｜以便**：Speak a little more slowly **so that** I can take notes. → 说慢一点，好让我记笔记。
- **in order that｜为了，较正式**：We simplified the instructions **in order that** beginners could follow them. → 我们简化了说明，以便初学者能够照着操作。

**结果：前面的情况带来了什么后果**

- **so｜因此；所以**：The file was too large to email, **so** I shared a link. → 文件太大，无法用邮件发送，所以我分享了链接。
- **so that｜结果使得，较书面**：A pipe burst, **so that** the room was flooded. → 一根水管爆裂了，结果房间被水淹了。
- **so ... that ...｜如此……以至于……**：The text was **so** small **that** I couldn't read it. → 字太小了，以至于我看不清。
- **such ... that ...｜如此……以至于……，such 后接名词短语**：It was **such** a useful example **that** I wrote it down. → 这个例子太有用了，所以我把它记了下来。

**方式与假设比较**

- **as｜按照……的方式**：Please arrange the files **as** I showed you. → 请按照我演示的方式整理文件。
- **as if｜仿佛**：He speaks **as if** he knows all the answers. → 他说话的样子仿佛什么答案都知道。
- **as though｜好像，与 as if 意义接近**：She looked **as though** she hadn't slept. → 她看起来好像没睡觉。

**程度比较**

- **than｜比，后接比较从句**：I have more time today **than** I had yesterday. → 我今天的时间比昨天多。
- **as ... as ...｜和……一样……**：This version is **as** clear **as** the first one. → 这个版本和第一个一样清楚。
- **not as ... as ...｜不如……那么……**：The answer was **not as** simple **as** I expected. → 答案没有我预想的那么简单。
- **not so ... as ...｜不如……那么……，较书面**：The task was **not so** difficult **as** I had expected. → 这项任务没有我原先预想的那么难。

**地点**

- **where｜在……的地方**：Leave the keys **where** you can find them easily. → 把钥匙放在你容易找到的地方。
- **wherever｜无论在什么地方**：Sit **wherever** you feel comfortable. → 坐在任何你觉得舒服的位置吧。

**陈述内容与是否**

- **that｜引出所说、所想、所知的内容**：I know **that** you are busy this week. → 我知道你这周很忙。
- **if｜是否，引出间接疑问**：Do you know **if** the library is open today? → 你知道图书馆今天是否开门吗？
- **whether｜是否，引出两种可能**：I haven't decided **whether** I should go. → 我还没决定是否应该去。

**例外与补充限制**

- **except that｜只是；除了……这一点**：The room was perfect **except that** it was noisy at night. → 这个房间很理想，只是晚上有些吵。
- **save that｜除了……这一点，较正式**：The plans were identical, **save that** one included an extra day. → 两个计划一模一样，只是其中一个多安排了一天。

## 6. 介词

### 6.1 常见单词介词

按字母顺序整理，不按“时间、空间、关系”互斥分类，因为同一个介词可以表达多种关系。

| 字母范围 | 单词 |
| --- | --- |
| A | aboard, about, above, across, after, against, along, alongside, amid, amidst, among, amongst, around, as, astride, at, atop |
| B–D | before, behind, below, beneath, beside, besides, between, beyond, but, by, despite, down, during |
| E–I | except, for, from, in, inside, into |
| L–O | like, near, of, off, on, onto, opposite, outside, over |
| P–S | past, round, since |
| T–W | than, through, throughout, till, to, toward, towards, under, underneath, unlike, until, up, upon, versus, via, with, within, without |

`amid/amidst`、`among/amongst`、`toward/towards` 为常见变体。`but`、`than`、`as` 是否归入介词，也取决于具体用法和所采用的语法体系。


**语境例句**

**A 组：位置、方向与角色**

- **aboard｜在交通工具上，后接对象**：We were already **aboard** the train when you called. → 你打电话时，我们已经在火车上了。
- **about｜关于**：We talked **about** tomorrow's meeting. → 我们谈了明天的会议。
- **above｜在……上方**：The clock is **above** the door. → 钟在门的上方。
- **across｜横过；从一边到另一边**：She walked **across** the street to the café. → 她穿过街道去了咖啡馆。
- **after｜在……之后，后接名词**：We went for a walk **after** lunch. → 午饭后，我们去散了步。
- **against｜倚靠；与……相接触**：Please don't lean your bike **against** the door. → 请不要把自行车靠在门上。
- **along｜沿着**：Walk **along** this road until you reach the station. → 沿着这条路走，直到车站。
- **alongside｜在……旁边，常有并排意味**：A narrow path runs **alongside** the river. → 一条小路沿着河边延伸。
- **amid｜在……之中，较书面**：She stayed calm **amid** all the noise. → 在一片嘈杂声中，她保持着冷静。
- **amidst｜在……之中，amid 的变体**：The house stood **amidst** tall trees. → 房子坐落在高大的树木之间。
- **among｜在多个对象之中**：I found your note **among** the papers on my desk. → 我在桌上的文件中找到了你的便条。
- **amongst｜在……之中，among 的变体**：The answer is somewhere **amongst** these notes. → 答案就在这些笔记里的某个地方。
- **around｜在……周围**：We sat **around** the table and discussed the plan. → 我们围坐在桌旁讨论计划。
- **as｜作为，说明角色**：She works **as** a translator. → 她担任翻译。
- **astride｜跨坐在……上，较少见**：The child sat **astride** a low wall. → 那个孩子跨坐在一堵矮墙上。
- **at｜在某个地点**：I'll meet you **at** the station entrance. → 我会在车站入口处和你见面。
- **at｜在某个具体时刻**：The meeting starts **at** nine. → 会议九点开始。
- **atop｜在……顶上，较书面**：A small flag stood **atop** the tower. → 塔顶上立着一面小旗。

**B–D 组：先后、相对位置与其他关系**

- **before｜早于某个时间或事件，后接名词**：I had finished the first task **before** lunch, so I took a break. → 午饭前我已经完成了第一项任务，于是休息了一会儿。
- **behind｜在……后面**：Your bag is **behind** the chair. → 你的包在椅子后面。
- **below｜在……下方；低于**：Write your answer **below** the question. → 把答案写在问题下面。
- **beneath｜在……下面，较书面**：The note was hidden **beneath** a pile of papers. → 便条藏在一叠文件下面。
- **beside｜在……旁边**：I sat **beside** Mia so we could share the book. → 我坐在米娅旁边，好让我们共用这本书。
- **besides｜除……之外还**：**Besides** English, she studies French. → 除英语外，她还学法语。
- **between｜在……之间**：There is a clear difference **between** these two sentences. → 这两个句子之间有明显的区别。
- **beyond｜超出某个范围**：That question is **beyond** my experience; let's ask someone else. → 那个问题超出了我的经验范围，我们问问别人吧。
- **but｜除……以外**：Everyone **but** Tom has replied. → 除了汤姆，所有人都回复了。
- **by｜不晚于；到……为止**：The report must be ready **by** Friday. → 报告最迟星期五必须准备好。
- **by｜由，标明被动句中的动作执行者**：This note was written **by** Mia. → 这张便条是米娅写的。
- **despite｜尽管，后接名词性成分**：**Despite** the noise, I managed to finish the task. → 尽管很吵，我还是设法完成了任务。
- **down｜沿着……向下**：Walk **down** the stairs and turn left. → 走下楼梯，然后左转。
- **during｜在某段时间或活动期间**：Please keep your phone silent **during** the meeting. → 开会期间，请将手机静音。

**E–I 组：排除、目的、来源与进入**

- **except｜除……以外**：Everyone arrived on time **except** me. → 除了我，大家都准时到了。
- **for｜给；为了某个受益者**：I printed a copy **for** you. → 我给你打印了一份。
- **for｜持续多长时间**：We worked **for** two hours before lunch. → 午饭前，我们工作了两个小时。
- **from｜来自；来源**：I received a message **from** my teacher. → 我收到了一条老师发来的消息。
- **in｜在……内部**：The keys are **in** the drawer. → 钥匙在抽屉里。
- **in｜在月份、年份等时间范围内**：The course begins **in** April. → 课程四月开始。
- **inside｜在……里面，后接对象**：There's a spare key **inside** the box. → 盒子里有一把备用钥匙。
- **into｜进入，强调移动后的方向或状态**：She walked **into** the room and closed the door. → 她走进房间，关上了门。

**L–O 组：相似、邻近、所属与表面位置**

- **like｜像，与某对象相似**：Your idea is **like** mine, but the details are different. → 你的想法和我的相似，但细节不同。
- **near｜在……附近**：There's a quiet café **near** the office. → 办公室附近有一家安静的咖啡馆。
- **of｜连接内容、所属或关联对象**：What is the purpose **of** this meeting? → 这次会议的目的是什么？
- **off｜离开某个表面**：Please take your bag **off** the table. → 请把包从桌子上拿走。
- **on｜在……表面**：I left the note **on** your desk. → 我把便条留在了你的桌上。
- **on｜在具体某一天**：We can discuss the details **on** Monday. → 我们可以周一讨论细节。
- **onto｜到……上面，强调移动**：The cat jumped **onto** the chair. → 猫跳到了椅子上。
- **opposite｜在……对面**：The café is **opposite** the station. → 咖啡馆在车站对面。
- **outside｜在……外面，后接对象**：I'll wait **outside** the main entrance. → 我会在正门外面等。
- **over｜在……上方跨越**：We walked **over** the bridge to the old town. → 我们走过桥，到了老城区。

**P–S 组：经过、环绕与起点**

- **past｜经过，继续向前**：I walked **past** the office without going in. → 我从办公室旁经过，没有进去。
- **round｜围着；绕着，常见于英式英语**：We walked **round** the lake before going home. → 回家前，我们绕着湖走了一圈。
- **since｜自某个时间点以来**：I've lived here **since** 2020. → 我从 2020 年起一直住在这里。

**T–W 组：比较、路径、时间边界与伴随**

- **than｜比，后接比较对象**：She's taller **than** me. → 她比我高。（本表采用可将 than 分析为介词的教学口径。）
- **through｜穿过某物内部或范围**：We walked **through** the park to reach the station. → 我们穿过公园到达车站。
- **throughout｜贯穿整个期间**：He remained quiet **throughout** the meeting. → 他整场会议都保持安静。
- **till｜直到某个时刻，与 until 意义接近**：I'll be here **till** six. → 我会一直在这里待到六点。
- **to｜到，指目的地**：We walked **to** the station. → 我们走到了车站。
- **to｜给，指接受者**：Please send the final version **to** Mia. → 请把最终版本发给米娅。
- **toward｜朝向**：He turned **toward** the door when he heard the noise. → 听见响声时，他转向了门口。
- **towards｜朝向，toward 的变体**：She walked **towards** the station entrance. → 她朝车站入口走去。
- **under｜在……下方**：The spare chair is **under** the stairs. → 备用椅子在楼梯下面。
- **underneath｜在……下面，常强调被覆盖的位置**：I found the note **underneath** my notebook. → 我在笔记本下面找到了便条。
- **unlike｜与……不同**：**Unlike** the first example, this one refers to the future. → 与第一个例子不同，这个说的是将来。
- **until｜一直到某个时间为止**：The library is open **until** eight. → 图书馆一直开放到八点。
- **up｜沿着……向上**：We walked **up** the hill to see the view. → 我们沿着山坡向上走，去看风景。
- **upon｜一到；在……时，较正式**：**Upon** arrival, please check in at reception. → 到达后，请在接待处登记。
- **versus｜与……对比；与……相对**：The discussion focused on cost **versus** quality. → 讨论集中在成本与质量的对比上。
- **via｜通过；经由**：Please send the document **via** email. → 请通过电子邮件发送文件。
- **with｜和……一起**：I discussed the problem **with** a colleague. → 我和一位同事讨论了这个问题。
- **with｜用某种工具**：Please mark the important words **with** a pen. → 请用笔标出重要的词。
- **within｜在某个范围或期限内**：Please reply **within** two days. → 请在两天内回复。
- **without｜没有；不做某事**：Don't send the file **without** checking the address first. → 先检查地址，再发文件；不要不检查就发送。

### 6.2 较正式或由其他词类转化的介词

| 细分类别 | 单词 |
| --- | --- |
| 较正式、书面或专业表达 | circa, notwithstanding, per, respecting, save |
| 常见分词形式 | barring, concerning, considering, excepting, excluding, failing, following, given, including, pending, regarding |
| 加减关系 | minus, plus |

这些词在相应用法中作介词；它们并非在所有句子中都属于介词。例如，`following the instructions` 也可能是动词 `follow` 的分词结构，需结合上下文判断。


**语境例句**

**较正式、书面或专业表达**

- **circa｜大约在某个年代**：The photograph was taken **circa** 1950. → 这张照片大约拍摄于 1950 年。
- **notwithstanding｜尽管，较正式**：**Notwithstanding** the delay, we finished on time. → 尽管有所延误，我们还是按时完成了。
- **per｜每，表示比率**：We practise English for ten minutes **per** day. → 我们每天练习十分钟英语。
- **respecting｜关于，较正式，日常常用 about 或 regarding**：I have a question **respecting** the proposed changes. → 我有一个关于拟议改动的问题。
- **save｜除……以外，较书面**：Everyone **save** Tom had left. → 除了汤姆，所有人都已经离开了。

**分词形式作介词：根据后接成分理解关系**

- **barring｜除非有；如果没有意外情况**：**Barring** delays, we'll be home by six. → 如果没有延误，我们六点前就能到家。
- **concerning｜关于**：I received an email **concerning** Friday's meeting. → 我收到了一封关于周五会议的邮件。
- **considering｜考虑到**：**Considering** the weather, we were lucky to arrive on time. → 考虑到天气状况，我们能准时到达已经很幸运了。
- **excepting｜除……以外，较正式**：The building is open every day, **excepting** Sundays. → 这栋楼除星期日外每天都开放。
- **excluding｜不包括**：The price is twenty pounds, **excluding** delivery. → 价格是二十英镑，不含运费。
- **failing｜如果某个选择不行**：We can meet on Tuesday or, **failing** that, on Friday. → 我们可以周二见面，如果周二不行，那就周五。
- **following｜在……之后**：The office will be closed **following** the meeting. → 会议结束后，办公室将关闭。
- **given｜鉴于**：**Given** the time available, we've made good progress. → 考虑到可用时间有限，我们的进展已经不错了。
- **including｜包括在内**：Six people are coming, **including** Mia. → 包括米娅在内，一共六个人会来。
- **pending｜等待……期间；在……完成前，较正式**：We kept the room closed **pending** a safety inspection. → 我们关闭了房间，等待安全检查。
- **regarding｜关于**：I'll email you **regarding** the change of date. → 我会发邮件给你，说明日期变更的事。

**加减关系**

- **minus｜减去**：The total is fifty pounds **minus** the discount. → 总额是五十英镑减去折扣金额。
- **plus｜加上；另外还有**：We have ten minutes **plus** a short break. → 我们有十分钟，另外还有一小段休息时间。

### 6.3 常见复合介词和介词性短语

| 关系 | 短语 |
| --- | --- |
| 位置、方向 | ahead of, close to, far from, in front of, inside of, near to, next to, on top of, out of, outside of |
| 原因、依据 | because of, due to, on account of, owing to, thanks to, according to |
| 补充、排除、替代 | apart from, as well as, except for, in addition to, in place of, instead of |
| 让步、话题、举例 | in spite of, as for, with regard to, such as |
| 范围、其他关系 | as of, as to, up to, together with |

复合介词与一般介词短语之间的边界并不完全统一，本节收录常见学习项目。参见 [Cambridge：介词及复合介词](https://dictionary.cambridge.org/us/grammar/british-grammar/prepositions_2)。


**语境例句**

**位置与方向短语**

- **ahead of｜在……前面；进度领先**：We finished the first part **ahead of** the other team. → 我们比另一队先完成第一部分。
- **close to｜靠近**：I'd like a room **close to** the station. → 我想要一间靠近车站的房间。
- **far from｜离……远**：My office is **far from** home, so I take the train. → 我的办公室离家很远，所以我坐火车。
- **in front of｜在……前面**：There's a notice **in front of** the entrance. → 入口前有一张告示。
- **inside of｜在……里面，常见于美式表达**：Keep the note **inside of** the folder so it doesn't get lost. → 把便条放在文件夹里面，以免弄丢。
- **near to｜靠近**：The meeting room is **near to** the main entrance. → 会议室靠近正门。
- **next to｜紧挨着**：Please sit **next to** me so we can share the notes. → 请坐在我旁边，好让我们共用笔记。
- **on top of｜在……顶部**：I put the notebook **on top of** the papers. → 我把笔记本放在文件上面。
- **out of｜从……里面出来**：She took a pen **out of** her bag. → 她从包里拿出一支笔。
- **outside of｜在……外面**：Please wait **outside of** the main entrance. → 请在正门外面等。

**原因与依据短语**

- **because of｜由于，后接名词性成分**：The meeting was delayed **because of** the traffic. → 会议因交通拥堵而推迟。
- **due to｜由于**：The train was late **due to** a signal problem. → 火车因信号问题晚点。
- **on account of｜由于，较正式**：The event was cancelled **on account of** heavy rain. → 活动因大雨而取消。
- **owing to｜由于，较书面**：The office opened late **owing to** a power cut. → 办公室因停电而晚些开门。
- **thanks to｜多亏**：We finished early **thanks to** your help. → 多亏你的帮助，我们提前完成了。
- **according to｜根据；按照某个消息来源**：**According to** the timetable, the train leaves at six. → 根据时刻表，火车六点出发。

**补充、排除与替代短语**

- **apart from｜除……之外，这里表示排除**：Everyone agreed **apart from** Tom. → 除了汤姆，所有人都同意。
- **as well as｜除了……还；也**：She checks the details **as well as** the overall meaning. → 她既检查细节，也检查整体含义。
- **except for｜除了某个例外**：The report was complete **except for** the final page. → 报告已经完整了，只差最后一页。
- **in addition to｜除……之外还**：**In addition to** the notes, you'll receive an audio file. → 除了笔记，你还会收到一个音频文件。
- **in place of｜代替**：We used a short example **in place of** a long explanation. → 我们用一个简短的例子代替了长篇解释。
- **instead of｜而不是；代替**：I took notes **instead of** trying to remember everything. → 我做了笔记，而不是试图把一切都记住。

**让步、话题与举例短语**

- **in spite of｜尽管，后接名词性成分**：We enjoyed the walk **in spite of** the rain. → 尽管下雨，我们还是享受了这次散步。
- **as for｜至于，转换话题**：The room looks fine. **As for** the price, we still need to ask. → 房间看起来不错，至于价格，我们还得问问。
- **with regard to｜关于，较正式**：I'm writing **with regard to** your question about the course. → 我写信是为了回应你关于课程的问题。
- **such as｜例如，后接所列举的对象**：Learn useful expressions **such as** “in other words” and “for example”. → 学习有用的表达，例如 in other words 和 for example。

**范围与其他关系短语**

- **as of｜从某个日期起；截至某时，依上下文判断**：**As of** Monday, the office will open at eight. → 从周一起，办公室将于八点开放。
- **as to｜关于；至于**：There's some uncertainty **as to** the best time to begin. → 关于何时开始最合适，目前还不确定。
- **up to｜最多；达到某个上限**：The room can hold **up to** twenty people. → 这个房间最多能容纳二十人。
- **together with｜连同；和……一起**：Send the form **together with** a copy of your ID. → 请把表格连同身份证明复印件一起发送。

## 7. 疑问词

| 细分类别 | 单词 |
| --- | --- |
| 疑问副词 | when, where, why, how |

疑问代词 `who`、`whom`、`whose`、`what`、`which` 见第 3 节。


**语境例句**

**疑问副词：问时间、地点、原因与方式**

- **when｜什么时候**：**When** did you finish the report? → 你什么时候完成了报告？
- **where｜在哪里**：**Where** did you save the file? → 你把文件保存在了哪里？
- **why｜为什么**：**Why** did she leave before the meeting ended? → 会议还没结束，她为什么就离开了？
- **how｜怎样；通过什么方式**：**How** did you find the correct address? → 你是怎样找到正确地址的？

## 8. 小品词

### 8.1 基本分类

| 细分类别 | 单词或形式 |
| --- | --- |
| 不定式标记 | to |
| 否定标记 | not, n't |

`n't` 是附着在助动词或情态动词上的否定缩写形式，通常不作为独立单词使用。


**语境例句**

**不定式与否定标记**

- **to｜接在动词原形前，构成不定式**：I want **to** understand the whole sentence. → 我想理解整个句子。
- **not｜否定**：We are **not** ready to decide yet. → 我们还没准备好作决定。
- **n't｜附着式否定缩写，isn't 等于 is not**：She **isn't** ready yet; give her a minute. → 她还没准备好，给她一点时间。

| under | go under |
| up | give up |

这里采用学习语法中较宽的“副词小品词”口径；个别形式在不同语法体系中也可能按普通副词分析。`forth` 较书面，`round` 常见于英式英语。参见 [Cambridge：短语动词与多词动词](https://dictionary.cambridge.org/uk/grammar/british-grammar/phrasal-verbs)。

另一个特殊形式是 `to`，如 `come to` 表示“苏醒”。此处 `to` 既不是不定式标记，也没有后接介词宾语。参见 [Cambridge：come to](https://dictionary.cambridge.org/dictionary/english/come-to)。

小品词与介词要按结构区分：`look up the word` 中的 `up` 是小品词，可以说 `look the word up`；`look at the picture` 中的 `at` 是介词，不能说 `look the picture at`。


**语境例句**

**在短语动词中看整体含义**

- **about｜mess about：胡闹；磨蹭**：Please stop **messing about** and get ready. → 别再磨蹭了，准备好吧。
- **across｜get across：把意思讲清楚**：I couldn't **get** my point **across** until I gave an example. → 直到举了例子，我才把观点讲清楚。
- **ahead｜go ahead：开始做；请便**：**Go ahead** and ask your question. → 请尽管问你的问题。
- **along｜get along：相处**：Do you **get along** with your new colleagues? → 你和新同事相处得好吗？
- **apart｜take apart：拆开**：Don't **take** the clock **apart**; we may not be able to put it back together. → 别把钟拆开，我们可能装不回去。
- **around｜hang around：逗留；等着**：We **hung around** for ten minutes before the bus arrived. → 公交车到达前，我们在附近等了十分钟。
- **aside｜put aside：暂时放到一边**：Let's **put** this question **aside** and return to it later. → 我们先把这个问题放到一边，晚些时候再来讨论。
- **away｜put away：收起来**：Please **put** your notes **away** before the test begins. → 测试开始前，请把笔记收起来。
- **back｜give back：归还**：I'll **give** your book **back** tomorrow. → 我明天会把书还给你。
- **behind｜leave behind：留下；忘记带走**：Don't **leave** your notebook **behind** when we go. → 我们走的时候，别把笔记本落下。
- **by｜get by：勉强应付；维持下去**：We can **get by** with one computer for a week. → 只有一台电脑，我们也能应付一个星期。
- **down｜turn down：调低**：Could you **turn** the music **down**? I need to concentrate. → 你能把音乐音量调低一点吗？我需要专心。
- **forth｜bring forth：引出；产生，较书面**：The discussion **brought forth** several useful ideas. → 这次讨论产生了几个有用的想法。
- **forward｜put forward：提出**：She **put forward** a simpler plan. → 她提出了一个更简单的计划。
- **in｜bring in：引入；请来**：The team **brought in** an expert to help explain the problem. → 团队请来了一位专家，帮助解释这个问题。
- **off｜take off：起飞**：The plane **took off** just after sunrise. → 飞机在日出后不久起飞了。
- **on｜carry on：继续**：Please **carry on** reading while I answer the phone. → 我接电话时，请继续阅读。
- **out｜find out：查明；弄清**：I finally **found out** why the link didn't work. → 我终于弄清楚链接为什么打不开了。
- **over｜think over：仔细考虑**：I'll **think** it **over** and let you know tomorrow. → 我会仔细考虑一下，明天告诉你。
- **round｜come round：来访，常见于英式英语**：Would you like to **come round** for tea on Sunday? → 你愿意星期日过来喝茶吗？
- **through｜see through：坚持完成**：Despite the delay, we **saw** the project **through**. → 尽管有所延误，我们还是把项目坚持做完了。
- **together｜put together：组装；拼合**：Can you **put** these pieces **together**? → 你能把这些零件组装起来吗？
- **under｜go under：倒闭，在本例中指经营失败**：The small shop **went under** after it lost its main customer. → 那家小店失去主要客户后倒闭了。
- **up｜give up：放弃**：She **gave up** trying to repair the old printer. → 她放弃了修理那台旧打印机。

**正文提到的特殊形式 to**

- **to｜come to：苏醒，没有后接介词宾语**：After a few minutes, he **came to** and looked around. → 几分钟后，他苏醒过来，环顾四周。

## 9. 原文补充的功能表达

以下保留原文的功能分组。它们与前面的词类存在重叠，尤其“程度表达”只是常见示例，不代表程度副词构成一个可穷尽的封闭词类。

| 功能 | 单词或表达 |
| --- | --- |
| 比较标记 | than, as, more, most, less, least |
| 否定表达 | no, not, never, neither, nor |
| 程度表达 | very, too, so, quite, rather, enough |
| 存在句与形式主语 | there, it |
| 边缘情态表达 | ought to, used to, need, dare |

`there` 用于存在句，`it` 可作形式主语；`need`、`dare` 也有普通实义动词用法。


**语境例句**

**比较标记：比较程度**

- **than｜比**：This version is easier to read **than** the first one. → 这个版本比第一个更容易读懂。
- **as｜与另一个 as 配合，表示程度相同**：This explanation is **as** clear **as** yesterday's. → 这个解释和昨天的一样清楚。
- **more｜更加，修饰形容词**：The final question was **more** difficult than I expected. → 最后一个问题比我预想的更难。
- **most｜最，构成最高级**：Of all these chapters, I found this one the **most** useful. → 在这些章节中，我觉得这一章最有用。
- **less｜较不；程度较低**：This version is **less** complicated than the old one. → 这个版本没有旧版本那么复杂。
- **least｜程度最低**：This is the **least** expensive option. → 这是最便宜的选项。

**否定表达**

- **no｜没有，放在名词前**：We have **no** time for the longer version today. → 今天我们没有时间看更长的版本。
- **not｜否定前面或后面的判断**：The answer is **not** wrong; it just needs more detail. → 这个答案并没有错，只是需要更多细节。
- **never｜从不；从未**：I've **never** met her, so I don't know what she looks like. → 我从未见过她，所以不知道她长什么样。
- **neither｜也不，接前面的否定**：I don't drive, and **neither** does Mia. → 我不开车，米娅也不开。
- **nor｜也不，补充另一个否定**：I don't have the address, **nor** do I have his phone number. → 我没有地址，也没有他的电话号码。

**程度表达**

- **very｜很，修饰形容词或副词**：The instructions are **very** clear. → 这些说明很清楚。
- **too｜过于，超过适当程度**：The text is **too** small for me to read. → 字太小了，我看不清。
- **so｜这么；那么，强调程度**：That example was **so** useful! → 那个例子真是太有用了！
- **quite｜相当；颇**：The example is **quite** clear, though one word is new to me. → 这个例子相当清楚，虽然有一个词我不认识。
- **rather｜相当；有点，常带超出预期的意味**：The instructions are **rather** confusing. Could you explain them? → 说明有点让人困惑，你能解释一下吗？
- **enough｜足够，放在形容词后**：Your explanation is clear **enough** for me to follow. → 你的解释足够清楚，我能听懂。

**存在句与形式主语**

- **there｜引出存在，不指具体地点**：**There** is a question I'd like to ask. → 我有一个想问的问题。
- **it｜形式主语，具体内容在后面**：**It** is important to understand the context. → 理解语境很重要。

**边缘情态表达**

- **ought to｜应该**：We **ought to** check the details before sending the report. → 发送报告前，我们应该核对细节。
- **used to｜过去常常，而现在情况已改变**：I **used to** study only word lists; now I read example sentences too. → 我过去只学词表，现在也读例句。
- **need｜情态用法：needn't 接动词原形**：You **needn't** bring a copy; I've printed one for you. → 你不必带副本，我已经给你打印了一份。
- **dare｜情态用法：dare not 接动词原形**：I **dare not** ask him again. → 我不敢再问他了。

**need、dare 的普通动词用法**

- **need｜普通动词可用 don't need to do**：I **don't need to** leave yet; the train is late. → 我现在还不需要走，火车晚点了。
- **dare｜普通动词可用 didn't dare to do**：She **didn't dare to** ask another question. → 她没敢再问一个问题。

## 10. be、do、have 的词形

| 动词 | 词形数量 | 全部词形 |
| --- | --- | --- |
| be | 8 | be, am, is, are, was, were, been, being |
| do | 5 | do, does, did, done, doing |
| have | 4 | have, has, had, having |

上表统计不重复的完整拼写形式，不另计缩写形式，也不将一个拼写形式的多种语法功能重复计算。

**语境例句**

**be 的 8 个完整词形**

- **be｜原形，可用于祈使句等结构**：Please **be** quiet; the meeting has started. → 请安静，会议已经开始了。
- **am｜与 I 搭配的现在时形式**：I **am** ready to start. → 我准备好开始了。
- **is｜第三人称单数现在时，这里构成进行时**：She **is** checking the figures now. → 她现在正在核对数字。
- **are｜与复数主语或 you 搭配的现在时形式**：The files **are** on the desktop. → 文件在桌面上。
- **was｜过去时单数形式，you 通常用 were**：The office **was** empty when I arrived. → 我到的时候，办公室是空的。
- **were｜过去时形式，这里与 we 构成进行时**：We **were** working when the lights went out. → 灯熄灭时，我们正在工作。
- **been｜过去分词，这里跟在 have 后**：I have **been** here for an hour. → 我已经在这里待了一个小时。
- **being｜现在分词，这里构成进行时被动结构**：The document is **being** checked now. → 文件现在正在被检查。

**do 的 5 个完整词形**

- **do｜原形，这里是主要动词**：I **do** the first check every morning. → 我每天早上做第一次检查。
- **does｜第三人称单数现在时，这里是强调助动词**：This example **does** make the point clearer. → 这个例子确实让要点更清楚了。
- **did｜过去时，这里帮助构成疑问句**：**Did** you save the file before closing the program? → 关闭程序前，你保存文件了吗？
- **done｜过去分词，这里跟在 have 后**：I have **done** the first part already. → 我已经完成第一部分了。
- **doing｜现在分词，这里构成进行时**：I'm **doing** the exercise at the moment. → 我此刻正在做这道练习。

**have 的 4 个完整词形**

- **have｜原形或现在时，这里表示有**：We **have** two meetings this afternoon. → 我们今天下午有两个会议。
- **has｜第三人称单数现在时，这里构成完成时**：She **has** already read the report. → 她已经读过报告了。
- **had｜过去时形式，这里构成过去完成时**：By the time we ate lunch, I **had** finished the first task. → 到我们吃午饭时，我已经完成了第一项任务。
- **having｜现在分词，这里表示用餐的动作**：They're **having** lunch and will be back at two. → 他们正在吃午饭，两点回来。

例句为学习用原创内容；较正式表达的用法可核对 [Cambridge：lest](https://dictionary.cambridge.org/us/dictionary/english/lest)、[failing](https://dictionary.cambridge.org/us/dictionary/english/failing)、[pending](https://dictionary.cambridge.org/us/dictionary/english/pending)。`as long as` 的持续时间用法与条件用法可参见 [Cambridge 说明](https://dictionary.cambridge.org/grammar/british-grammar/as-long-)。
