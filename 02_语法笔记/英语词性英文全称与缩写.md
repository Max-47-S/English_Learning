# 英语词性英文全称与缩写

[返回语法笔记](README.md) · [英语封闭词类总览与例句](英语封闭词类总览.md)

**POS** 是 **part of speech** 的缩写，意思是“词性”。本表以 Oxford 3000 的标签为基础，补充常见语法细类。各词典的标法会有差异。像 `n.`、`v.`、`adj.` 是常见词典缩写，`poss. det.`、`freq. adv.` 等细类缩写可用于笔记。

## 1. 基础词类与标签

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 名词 | noun · `n.` | idea, work |
| 动词 | verb · `v.` | work, become |
| 形容词 | adjective · `adj.` | clear, ready |
| 副词 | adverb · `adv.` | already, quickly |
| 代词 | pronoun · `pron.` | she, mine |
| 限定词 | determiner · `det.` | **this** book |
| 冠词 | article · `art.` | a, an, the |
| 数词 | numeral / number · `num.` / `number` | three, third |
| 介词 | preposition · `prep.` | at, in, before |
| 连词 | conjunction · `conj.` | and, but, because |
| 感叹词 | interjection · `interj.` / `exclam.` | oh, ouch, wow |
| 小品词 | particle · `part.` | look **up**, turn **off** |
| 不定式标记 | infinitive marker · `inf. marker` | want **to** leave |

冠词可以归入限定词。Oxford 3000 把 `a/an` 标成 `indefinite article`，把 `the` 标成 `definite article`，把 `to` 的两种用法标成 `prep.` 和 `infinitive marker`。[Oxford 3000 原表](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf)

- Go **to** work. → 去上班。第一个用法的 `to` 是介词。
- I want **to** work. → 我想工作。这里的 `to` 标记不定式。

## 2. 动词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 主要动词／实义动词 | main verb / lexical verb · `main v.` / `lex. v.` | I **work** here. |
| 基本助动词 | primary auxiliary verb · `aux. v.` / `auxiliary v.` | **be** waiting, **have** left, **do** you know? |
| 情态动词 | modal verb / modal auxiliary verb · `modal v.` | can, could, may, might, must, shall, should, will, would |
| 半情态动词 | semi-modal verb · `semi-modal v.` | You **needn’t** wait. |
| 系动词 | linking verb / copular verb · `linking v.` / `cop. v.` | It **became** clear. |
| 及物动词 | transitive verb · `vt.` / `[T]` | **open** the door |
| 不及物动词 | intransitive verb · `vi.` / `[I]` | The baby **slept**. |
| 双及物动词 | ditransitive verb · `ditrans. v.` | **give** me a minute |
| 状态动词 | stative verb · `stative v.` | **know** the answer |
| 动态动词 | dynamic verb · `dynamic v.` | **run** to the station |
| 规则动词 | regular verb · `reg. v.` | work → worked |
| 不规则动词 | irregular verb · `irreg. v.` | go → went → gone |
| 短语动词 | phrasal verb · `phr. v.` / `phrasal verb` | **look up** a word |

情态动词属于广义的助动词。Oxford 3000 用 `auxiliary v.` 标记 `be`、`have`、`do` 作基本助动词的用法，用 `modal v.` 标记 `can`、`must` 等。它也把 `have to` 标成 `modal v.`。Cambridge 把 `have to` 归入其他表达情态意义的结构，和核心情态动词分开。[Oxford 3000 原表](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf) · [Cambridge 动词分类](https://dictionary.cambridge.org/grammar/british-grammar/main) · [Cambridge 情态分类](https://dictionary.cambridge.org/us/grammar/british-grammar/modal-verbs)

- **Had** you **worked** for two hours before lunch? → 午饭前你已经工作了两个小时吗？`had` 是助动词，`worked` 是主要动词的过去分词。
- I **had** lunch at noon. → 我中午吃了午饭。`had` 自己就是主要动词。
- She **has to** leave. / She **must** leave. → 她必须走了。主语是 `she` 时，`have` 变成 `has`，`must` 保持原形。

## 3. 限定词、数量词与数词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 定冠词 | definite article · `def. art.` | **the** door |
| 不定冠词 | indefinite article · `indef. art.` | **a** book, **an** idea |
| 指示限定词 | demonstrative determiner · `dem. det.` | **these** books |
| 物主限定词 | possessive determiner · `poss. det.` | **my** phone |
| 疑问限定词 | interrogative determiner · `interrog. det.` | **which** train? |
| 分配限定词 | distributive determiner · `distrib. det.` | **each** student, **every** day |
| 前置限定词 | predeterminer · `predet.` | **all** my friends |
| 数量词／数量限定词 | quantifier · `quant.` | **many** books, **much** time |
| 基数词 | cardinal number / cardinal numeral · `card. num.` | **three** books |
| 序数词 | ordinal number / ordinal numeral · `ord. num.` | the **third** chapter |

`three` 表示确切数量，`many` 表示数量多，`third` 表示顺序。Oxford 3000 把 `three` 和 `third` 都标为 `number`。像 *a **cup** of tea*（一杯茶）、*a **piece** of advice*（一条建议）中的 `cup` 和 `piece` 是用来计量的名词。[Cambridge 限定词分类](https://dictionary.cambridge.org/grammar/british-grammar/determiners_2) · [Oxford 3000 原表](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf)

## 4. 代词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 人称代词 | personal pronoun · `pers. pron.` | I, me, she, her |
| 主格代词 | subject pronoun · `subj. pron.` | **She** called me. |
| 宾格代词 | object pronoun · `obj. pron.` | She called **me**. |
| 物主代词 | possessive pronoun · `poss. pron.` | This phone is **mine**. |
| 指示代词 | demonstrative pronoun · `dem. pron.` | **These** are mine. |
| 反身代词 | reflexive pronoun · `refl. pron.` | She hurt **herself**. |
| 强调用法的代词 | intensive / emphatic pronoun · `emph. pron.` | She fixed it **herself**. |
| 相互代词 | reciprocal pronoun · `recip. pron.` | They help **each other**. |
| 不定代词 | indefinite pronoun · `indef. pron.` | someone, nobody, anything |
| 疑问代词 | interrogative pronoun · `interrog. pron.` | **Who** called? |
| 关系代词 | relative pronoun · `rel. pron.` | the person **who** called |

- This is **my** phone. → 这是我的手机。`my` 放在名词前，是物主限定词。
- This phone is **mine**. → 这部手机是我的。`mine` 独立使用，是物主代词。
- She hurt **herself**. → 她弄伤了自己。这里的 `herself` 指动作回到主语自身。
- She fixed it **herself**. → 她亲自把它修好了。这里的 `herself` 强调“亲自”。

[Cambridge 代词分类](https://dictionary.cambridge.org/us/grammar/british-grammar/pronouns_2)

## 5. 名词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 普通名词 | common noun · `common n.` | city, teacher |
| 专有名词 | proper noun · `proper n.` | London, Anna |
| 可数名词 | countable noun · `[C]` | book, idea |
| 不可数名词 | uncountable noun / mass noun · `[U]` | advice, information |
| 集合名词 | collective noun · `coll. n.` | team, family |
| 具体名词 | concrete noun · `concr. n.` | chair, phone |
| 抽象名词 | abstract noun · `abstr. n.` | freedom, patience |
| 复合名词 | compound noun · `compound n.` | bus stop, toothbrush |

同一个名词可以同时落在不同的细类中。比如 `team` 是普通名词、可数名词和集合名词。可数性还要看具体义项。*I like **coffee***（我喜欢喝咖啡）里的 `coffee` 指饮品本身，*Two **coffees**, please*（请来两杯咖啡）里的 `coffees` 指两份饮品。[Cambridge 名词分类](https://dictionary.cambridge.org/grammar/british-grammar/nouns-types-of-nouns) · [Cambridge 词典标签说明](https://dictionary.cambridge.org/us/help/codes)

## 6. 形容词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 定语用法的形容词 | attributive adjective · `attrib. adj.` | a **clear** answer |
| 表语用法的形容词 | predicative adjective · `pred. adj.` | The answer is **clear**. |
| 分词形容词 | participial adjective · `participial adj.` | a **boring** film, a **bored** child |

`clear` 在名词前作定语，跟在系动词后作表语。*The instructions became **clear** after the demo.* → 看过演示之后，说明就清楚了。这里 `became` 是系动词，`clear` 是形容词。[Cambridge 形容词位置](https://dictionary.cambridge.org/us/grammar/british-grammar/adjective-phrases-position)

## 7. 副词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 方式副词 | adverb of manner · `manner adv.` | carefully, slowly |
| 时间副词 | adverb of time · `time adv.` | now, soon, already |
| 地点副词 | adverb of place · `place adv.` | here, nearby |
| 频率副词 | adverb of frequency · `freq. adv.` | often, rarely, twice |
| 程度副词 | adverb of degree · `degree adv.` | very, quite, almost |
| 聚焦副词 | focusing adverb · `focus adv.` | only, even, especially |
| 句子副词 | sentence adverb · `sentence adv.` | fortunately, frankly |
| 连接副词 | linking adverb / conjunctive adverb · `linking adv.` | however, therefore |
| 疑问副词 | interrogative adverb · `interrog. adv.` | **Where** do you work? |
| 关系副词 | relative adverb · `rel. adv.` | the place **where** I work |

*The shop was closed. **However**, we could still order online.* → 店已经关了，不过我们仍然可以在网上下单。`however` 在这里是连接副词，表明前后两句有转折关系。[Cambridge 副词分类](https://dictionary.cambridge.org/grammar/british-grammar/adverbs-types)

## 8. 连词

| 中文 | 英文全称和缩写 | 例子 |
| --- | --- | --- |
| 并列连词 | coordinating conjunction · `coord. conj.` | and, or, but |
| 从属连词 | subordinating conjunction · `subord. conj.` | because, although, if |
| 关联连词 | correlative conjunction · `corr. conj.` | either … or, neither … nor |

*The shop was closed, **but** we could still order online.* → 店已经关了，但我们仍然可以在网上下单。这里用并列连词 `but` 在同一句中连接两个分句。[Cambridge 连词分类](https://dictionary.cambridge.org/us/grammar/british-grammar/linking-words)

## 9. 一个词的多种词性

Oxford 3000 中的 `before` 有 `prep.`、`conj.` 和 `adv.` 三个标签。先看它在句子里接了什么，再看它起的作用。

| 例句 | 本句的词性 |
| --- | --- |
| **Before** lunch, I called her. → 午饭前我给她打了电话。 | `prep.`，接名词 `lunch` |
| I called her **before** she left. → 她离开前我给她打了电话。 | `conj.`，引导从句 `she left` |
| I’ve seen her **before**. → 我以前见过她。 | `adv.`，表示“以前” |

## 10. 词形与短语标签

查词时还会遇到描述**词形**和**短语类别**的标签。比如 `had worked` 整体是动词短语，`worked` 在其中是过去分词。

| 类别 | 英文全称 | 缩写 |
| --- | --- | --- |
| 单数 | singular | `sg.` |
| 复数 | plural | `pl.` |
| 不定式 | infinitive | `inf.` |
| 现在分词 | present participle | `pres. part.` |
| 过去分词 | past participle | `past part.` |
| 名词短语 | noun phrase | `NP` |
| 动词短语 | verb phrase | `VP` |
| 形容词短语 | adjective phrase | `AdjP` |
| 副词短语 | adverb phrase | `AdvP` |
| 介词短语 | prepositional phrase | `PP` |

[Cambridge 词典标签说明](https://dictionary.cambridge.org/us/help/codes) · [Cambridge 词类与短语类别](https://dictionary.cambridge.org/us/grammar/british-grammar/phrase)
