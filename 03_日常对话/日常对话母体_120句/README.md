## 第一回就这样练

先练 D01 的 M001—M004：问发生什么、说原因、问怎么解决、说自己的行动。再把通勤换成学习或设备问题。每天可以用 12—15 分钟练一段；句式不熟时，多留几次练习，不必按天数赶进度。

搭档提示：**你问一句，我答一句；先让我回答，再给提示；练完后换一个话题，骨架尽量保持，必要的语法跟着变。**

## 怎样理解‘套用’

可以保留提问、解释、比较等功能和句法关系。更换人称、时态、名词的数或动词搭配时，相应形式也要一起调整。主文件里的槽位写明应放名词、完整句子、动词原形还是 V-ing；例句演示怎样换，不建议整句只做字面替词。
