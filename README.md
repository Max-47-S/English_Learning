## 文件夹怎么分

```text
01_词汇与短语/   Oxford 3000、750 短语、高频词与统计
02_语法笔记/     时态、封闭词类等语法整理
03_日常对话/     120 句母体、跟读稿、句式地图与接话工具
04_阅读练习/     阅读文章与抄写材料
06_原始资料/     原始词表 PDF、旧 TXT 原稿
99_维护工具/     生成、下载、打包与校验脚本
```

每个学习包中的 `audio/` 保存音频，`data/` 保存词条和时间轴。相关来源说明、署名与许可随学习包保留。

## 听读网页怎么打开

下载仓库后，进入对应学习包，使用浏览器打开 `连续听读.html`，并保留旁边的 `audio/` 文件夹。GitHub 的文件预览页可以查看内容，播放需要在本地浏览器打开。

点击“上一词／上一条”“下一词／下一条”或“重听”，会播放目标词条并在读完后暂停。点击音频栏的播放按钮或拖动进度条，恢复连续播放。

## 两台电脑同步

开始学习前，在仓库文件夹执行 `git pull --ff-only`。修改并保存笔记后，提交改动，再执行 `git push`。播放器进度保存在当前浏览器本机。

脚本使用方法集中在 [维护工具说明](99_维护工具/README.md)。
